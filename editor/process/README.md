## Сейчас

**Активных опытов нет. Оба опыта от 2026-09-05 закрыты.**
Закрытие опыта означает завершённую оценку, а не обязательное внедрение его результата.
Новая сессия не продолжает закрытый опыт и не запускает проверки из старого отчёта сама.

| Часть процесса | Статус | Что это означает |

## Главная функция Codex

Верхнеуровневый Codex вместе с владельцем выбирает один видимый результат, записывает короткий
контракт, запускает видимую рабочую сессию Claude, остаётся в ожидании её точного конечного статуса,
проверяет контрольный коммит и по классу риска получает независимый вердикт. После `GO` Codex даёт
владельцу работающий адрес и короткую ручную проверку. Функциональный код редактора Codex по
умолчанию не пишет; принятие поведения владельцем не подменяет тестами и отчётами.

## Видимые сессии

Видимую сессию Claude запускают с `--remote-control --permission-mode auto`. После конечного статуса
её не закрывают: она остаётся в истории владельца, даже если процесс продолжает ждать ввода. `/exit`
допустим только по прямой просьбе владельца либо перед необходимым перезапуском с предварительным
предупреждением. Окончание работы определяется статусом нынешней операции, а не закрытием сессии.

## Обязательный отчёт Codex

1. Результат нынешней операции.
2. Ссылка или ID видимой сессии, её состояние и отметка, что сессия оставлена открытой.
3. Точные branch, base и head.
4. Какие файлы и какое пользовательское поведение изменены.
5. Какие проверки пройдены и какие не запускались.
6. Вердикт независимого контролёра, доказанные блокеры и остаточный риск.
7. Адрес работающей версии для личной пробы.
8. Одно точное действие владельца; если действий нет, это указывается прямо.

Отчёт даётся после окончания проверки в том же ходе. Владелец не переносит технические сведения
между помощниками и не обязан спрашивать, закончилась ли работа.

## Что дальше

**Новой работы по экспериментам не назначено.** Внедрение ожидания остаётся отдельным
предложением, а не незавершённым тестом и не разрешением начать работу.
Исправление позднего отчёта «Доработать» прошло независимый контроль, но ещё ждёт личной пробы
владельца; до неё функцию не считать принятой.
Приёмка прежнего пакета WebM/ссылки относится к редактору и не закрывается этим отчётом.

Если владелец назначит изменение процесса, здесь обновляются его статус и ссылка на результат.
Закрытый отчёт сохраняется как история; новый результат не переписывает прежние доказательства.
