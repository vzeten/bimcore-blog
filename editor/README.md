# Папка `editor/` в ветке сайта

Код редактора статей здесь **не лежит**. Единственная действующая версия кода — ветка `editor`,
рабочая копия `editor/.coordination/worktrees/accepted-editor/editor`; из неё работают ярлык, панель
и рабочий экземпляр 4780. Старый снимок кода от 12.09.2026 убран отсюда 2026-09-26 (ED-057, решение
владельца), чтобы его не принимали за текущий.

Здесь остаются только:

- правила работы помощников: `TASKS.md`, `REPORT.md`, `CURRENT_TASK.md`, `process/`;
- песочница `sandbox/` — учебная статья «Проба», её редактор показывает в дереве;
- данные редактора на компьютере владельца (история, черновики, корзина, аналитика, сверка) — они
  в Git не входят (`.gitignore`) и этой папкой не хранятся на сервере.
