## 2. Правило имени: таблица «вход → выход»

Имя строится из настройки `хранение.файлСостояния` (сегодня `_state.json`), а не пишется в коде.
Хвост настройки берётся без ведущих подчёркиваний, и имя всегда начинается с `_`: файл с
подчёркиванием Docusaurus не собирает (SPEC 2.7).

| Файл версии | Файл состояния | Почему так |
|---|---|---|
| `lessons/walls/index.mdx` | `lessons/walls/_state.json` | как сегодня, переноса нет |
| `lessons/walls/index.md` | `lessons/walls/_state.json` | признак `index` — по имени без расширения |
| `lessons/a.mdx` | `lessons/_a.state.json` | правило задания дословно |
| `lessons/a.b.mdx` | `lessons/_a.b.state.json` | имя без последнего расширения целиком |
| `lessons/a.md` и `lessons/a.mdx` | оба `lessons/_a.state.json` | названный крайний случай, п. 8 записки |

Регистр имени не меняется: правила регистронезависимых путей в проекте нет и заводить его здесь
нельзя (то же решение принято для ключа операции в З1б).
