## Польза

Владелец видит, что и когда менялось в статьях, и как после этого менялись показы и переходы из Google, по
всему сайту, языку и отдельной странице, — без таблиц и без Search Console.

## Результат (достаточно; вид — на усмотрение исполнителя, цельно и в стиле принятого окна просмотров)

1. Экран «Аналитика» из реестра (кнопка рядом с «Корзиной»); слева «Действия», «Поиск Google» и неактивное
   «Воронка продаж — скоро». Нет ключа (у сотрудника) — кнопки нет вовсе.
2. **Поиск Google:** график за 12 месяцев по неделям (показы и переходы) с метками событий «Действий» по их дате;
   месячный дальний обзор; щелчок по метке — дни вокруг события. Охват: весь сайт / RU / EN / ES / одна страница.
   Последние неполные дни отмечены и в сравнение 30/30 не входят. Список страниц: показы, переходы, CTR, позиция,
   разница 30 дней в штуках (зелёная/красная), сортировка; щелчок по странице — её график и её события.
3. **Действия:** лента изменений по дням — статья, языки, вид, строк +/−, описание от ИИ (или «без описания»);
   ручные SEO-события — отдельным видом; разница текста по щелчку; переход к графику страницы вокруг даты.
4. Ручки только чтения: события, ряды поиска по охвату и шагу, список страниц — из базы операции 1; секрет и
   текст разницы без запроса окну не уходят.

## Границы
