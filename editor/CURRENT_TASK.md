# Общее безопасное хранилище черновиков и истории

## Результат

Смена версии кода редактора не скрывает незавершённый текст и историю владельца: обычные экземпляры,
которые работают с `C:/My_code/bimcore-blog`, используют одно состояние материалов независимо от
пути рабочей копии кода. Несовпадающие старые черновики сохраняются и требуют явного выбора.

## Снимок

- board: `ED-028`; operation: `shared-draft-storage`; class: `3`; state: `selected`.
- branch: `fix/editor-shared-drafts`; base: `04326636162a30e026e922748c42ae6f7a26e470`.
- target: `editor`.
- worktree: `C:/My_code/bimcore-blog/editor/.coordination/worktrees/fix-editor-shared-drafts`.
- живой экземпляр до замены: `fix/editor-bold-formatting b2e03a56`, материалы
  `C:/My_code/bimcore-blog`, адрес `http://localhost:4780`.
- подтверждённый инцидент: черновик RU «Кровати для Revit» оказался в `.drafts` рабочей копии
  `fix-editor-draft-control` и исчез из окна после смены экземпляра; текст восстановлен.

## Границы

- Активные `.drafts` и `.history` определяются фактическим корнем материалов, а не папкой версии кода.
- Два обычных экземпляра из разных рабочих копий с одним корнем материалов видят одно состояние.
- Испытательный `EDITOR_TRIAL_ROOT` получает отдельное состояние и не читает состояние владельца.
- При переходе существующий черновик и история нынешнего экземпляра доступны новой версии без
  изменения статьи. Миграция повторяема и не удаляет исходные данные.
- Если найдено несколько разных старых черновиков одной версии статьи, ни один не выбирается,
  не объединяется и не удаляется молча; опасная запись останавливается с понятным сообщением.
- Старые рабочие копии, восстановленный файл, резервная копия, статьи, публикация, Git и ED-027
  не меняются. Не очищать `.drafts`, `.history`, `.trash` и незавершённые материалы.
- Текущий сервер `4780` не перезапускать до готового проверенного снимка; его активный черновик
  сначала сохранить в независимой резервной копии и доказать совпадение.

## Приёмка

- До кода итоговый замысел проверяет read-only контролёр класса 3.
- Адресные тесты: одинаковые материалы из двух путей кода; отдельный trial-root; один старый
  черновик; одинаковые копии; конфликт разных копий; повтор миграции; отказ записи при конфликте.
- Интеграционная проба на копии материалов: черновик создаётся в одном пути кода, второй путь видит
  тот же полный текст и историю, возврат к первому пути ничего не скрывает и не перезаписывает.
- Исходные старые хранилища после пробы существуют и совпадают побайтно; статьи не изменены.
- Типы; полный набор один раз; корпус без перезаписи; проверка путей Windows; итоговый контролёр.
- После `GO` обычный запуск использует `C:/My_code/bimcore-blog`, показывает восстановленный полный
  текст RU «Кровати для Revit» и переживает один повторный запуск без потери черновика.

Остановиться на `ready_for_review`. ED-027 остаётся непринятой и возвращается только после приёмки
этой операции владельцем.
