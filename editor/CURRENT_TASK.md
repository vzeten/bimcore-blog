## Поведение
Enter в абзаце пункта разбивает его на следующий пункт; без наследования loose.
В старом простом списке убираются межпунктовые зазоры всего затронутого списка.
Enter на пустом пункте выводит на уровень выше/из списка согласно существующему уровню.
Shift+Enter только перенос внутри того же абзаца/пункта; Enter после него создаёт пункт.
Кнопка: один задетый абзац = один пункт (не слово/физическая строка/пустой разделитель).
Смена вида не теряет вложения; повторное нажатие снимает список в отдельные абзацы.
Обычный набор, открытие и сохранение без структурного действия не нормализуют статью.
Сложные пункты сохраняют отдельные абзацы/код/картинки/вложения; не обещать им spread:false.
Абзац, заголовок, JSX, таблица и граница примечания не пересекаются слиянием.
Работа внутри :::note и :::tip та же; не расширять выделение за контейнер.
Backspace/Delete через межпунктовый зазор удаляет зазор, не склеивает маркеры/слова.
Сохранять уже принятое снятие маркера/уровня и удаление блоков; новых жестов не изобретать.
Точечные списки создаются с -, прежние знаки вне затронутого списка не нормализуются.
Простой список рядом с вложенным не получает общий отказ из-за невыделенного вложения.
Обычные действия должны применяться: сообщение вместо молчаливого вето G01 не исправление.
Undo/Redo возвращают всё структурное действие одной отменой, включая нормализацию.

## Границы кода: сохранить CodeMirror и MDX без второго хранения/пересборки документа
Переработать конфликтующие listKeys/listConvert, использовать общий разбор/отступы.
Удалить ненужные ветки и тесты неверных требований; не наслаивать новые обходы.
Предпочитать минимальные изменения диапазонов ради истории/цветов неизменённых слов.
Не ослаблять общую защиту скрытой разметки. Если требуется переписать обычное
редактирование/защиту блоков, остановиться с REFRAME_REQUIRED, не расширять молча.
Не менять публикацию/корзину/сохранение/контент/настройки безопасности. Только код списков
и необходимые интеграционные точки, адресные тесты и актуализация карты модулей.

## Регрессии ДО и ПОСЛЕ
Одинаковые реальные клавиши/выделения в EditorView: абзацы/заголовки Enter/ShiftEnter/
Backspace/Delete; границы примечаний; вложения/код/таблицы; изображение/видео/товар и
их выбор/удаление; жирный/курсив/ссылка; цвет неизменённых слов; Undo/Redo; read-only.
Новые сценарии списков (создание/смена/снятие/слияние/отмена) снаружи и внутри note/tip,
на копии реального проблемного черновика, со смешанными переносами и частичным выделением.
Проверять MDX установленным компилятором сайта с примечаниями, не только mdast.
Типы, адресные тесты, полный набор один раз в конце; корпус при смене чтения/записи;
сборка обязательна (меняется выдаваемый MDX). Записи проб только во временные данные.
Чужие грязные файлы не мусор: не удалять/stash/reset/add-A; коммит только явных путей.
run-status operation=list-rules running -> ready_for_review/failed/owner_required.
