# Выделение и предсказуемая работа со списками

## Результат

Владелец согласовал: убрать выделяемый технический хвост без изменения смысла выделения;
новый обычный список компактен, Enter на пустом пункте завершает его; Shift+Enter переносит
текст внутри пункта одинаково в окне и на сайте. Вернуть две кнопки списка с правильным
преобразованием абзацев и снятием списка без слипания текста.

Ветка: `fix/editor-remove-list-tools` -> `editor`. База этой правки: `3ae363b941ab61a2309266f3baeea8575248046e`.
Прежний пакет до этой базы не переносить автоматически. Push/merge до живой приёмки запрещены.
Класс 2. По последнему указанию владельца агенты Codex не используются; итоговую независимую
проверку точного diff проводит одноразовый Claude Opus. Верхний Codex проверяет живой результат.

## Границы этой операции

- Сначала отдельный контрольный коммит: отображение разделителя и Enter/Shift+Enter списка.
- Затем отдельный коммит: кнопки и чистое преобразование; не возвращать старую построчную list().
- Выделение: сначала CSS существующего md-sep. Не обрезать selection, не прятать переводы
  новым Decoration.replace, не менять карту документа. Обычный выбранный newline не запрещён.
- Enter: использовать штатные команды Markdown и их настройку, не дублировать движок списка.
  Устранить добавление лишних разделителей на выходе из пункта, не ломая абзацы/примечания.
- Старые намеренно разреженные и сложные списки не переписывать при открытии/сохранении.
- Преобразование: каждый затронутый абзац -> пункт компактного списка; пустые разделители
  не становятся пунктами. Переносы внутри абзаца, слова, inline-разметка и порядок сохраняются.
- Повторное нажатие активного типа: пункты -> отдельные абзацы; точную прошлую форму даёт Undo.
  Смена типа меняет только вид списка. Частичное выделение действует на затронутые абзацы/пункты.
- Не уплощать вложенность. Для структуры, которую нельзя преобразовать без потерь, отказ целиком,
  без частичных правок; использовать существующий способ сообщить ограничение. JSX/код не менять.
- Две знакомые пиктограммы списков, подсказки и активное состояние, без нового вложенного меню.
- Существующий разбор Markdown, карта поверхности и история. Без нового парсера, документа,
  хранения происхождения или косметического сокрытия настоящих ошибок.
- Не чинить соседние команды B/I/ссылки. Не менять публикацию, сохранение, пользовательские
  статьи, песочницу и её историю. Сохранить авторство и реальные удаления после 3ae363b.

## Приёмка

- Мышь и Shift+стрелки через абзацы/примечание: нет технического хвоста, текст выделяется;
  копирование, вырезание, Backspace/Delete и Undo сохраняют правильные границы и переводы.
- Новый маркированный/нумерованный список: несколько Enter, пустой пункт -> выход без
  самопроизвольного разрежения. Вложенность, Tab/Shift+Tab и обычные абзацы работают как раньше.
- Shift+Enter продолжает пункт, в MDX нет буквального служебного слеша на сайте.
- Абзацы -> оба списка -> абзацы, смена типа, смесь переносов, частичное выделение,
  отказ на неподдержанной структуре, Undo/Redo. Нет пустых пунктов и слипания слов.
- Живая проба в отдельном окне на моках/копии, без записи в статьи владельца; проверить
  реальные клавиши, DOM и MDX, цвета одинаковых строк, соседние примечания/изображение/видео.
- Адресные тесты и типы, полный набор один раз после последней правки; точные коммиты,
  handoff <=50 строк и run-status. Никакого объявления готовности по одним тестам.
