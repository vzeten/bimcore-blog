## Поведение
Вставить локальный WebM можно из меню видео через выбор файла, без ручного MDX.
WebM показывается видео с рабочими кнопками воспроизведения, без автозапуска.
Образец: RU/EN free-revit-families-risks/index.mdx, import sofaVideo и video/source.
Распознать эту безопасную форму без выполнения JSX/JavaScript.
Импорт и теги поддержанного видео не видны и не становятся строками для курсора.
В MDX они сохраняются: открытие/сохранение без правок побайтово неизменно.
Не скрывать произвольные неизвестные импорты, выражения и пользовательский текст.
GIF через вставку изображения виден и анимируется; YouTube/товар/изображение не ломаются.
Удаление WebM как цельного блока и Undo/Redo следуют уже принятым жестам редактора.
Импорт, используемый ещё где-то, не удалять вместе с одним блоком.
Подпись и обычный текст вокруг не теряются; форматирование текста не показывать на видео.
Использовать прежний карантин/размещение/отзыв и ограничения путей/чужой статьи/версии.
WebM определять по содержимому, не расширению; размер ограничить до приёма файла.
Не расширять HTTP25МБ; допустим WebM10МБ (base64 вписывается), обосновать в handoff.
При отказе нет битой ссылки и изменений статьи; переименование/конвертация GIF не нужны.
