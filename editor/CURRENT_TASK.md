## Польза

Сейчас «Доработать» сохраняет всё в PNG256: фото тяжелее JPEG до 1,9 раза, с полосами и сдвигом цвета, а после
публикации это не исправить. Владелец хочет максимум качества при минимуме веса без ручной сверки.

## Результат (достаточно)

1. Медиаподготовка «Доработать» для неподвижных JPG/PNG/WebP, которых нет на сайте (правила ED-051 сохраняются):
   ориентация, ширина до 1100 px; кандидаты — PNG с палитрой и JPEG (прозрачная по реальным пикселям — только PNG);
   берётся самый лёгкий, замена только при выигрыше ≥ 10 % и ≥ 10 КБ; картинка шире 1100 px уменьшается всегда.
2. Смена формата меняет расширение и ссылки; занятое имя отдаётся человеку. GIF и WebM не трогаются.
3. Повторный запуск ничего не меняет. Без библиотеки `sharp` — отказ словами, ни один файл не меняется.
4. Оригинал каждой изменяемой картинки и байты `index.mdx` до записи сохраняются в служебном хранилище при
   материалах (папка по `historyFolder(rel)`, вне статьи, Git и сайта; `/editor/.originals` в `.gitignore`)
   вместе с манифестом операции: имена было→стало, хеши, полный отпечаток снимка после записи. Не сохранилось —
   записи нет. **Кнопка возврата в эту операцию не входит** (сужено ведущим по контролю Fable 16.09): возврат —
   отдельной операцией после пробы конвертера, строго по манифесту и отказу при опубликованной статье.
4а. Условия контролёра до кода (Fable 5.1, 16.09): расширение обложки — по роду итоговых байтов (`cover.png`
   или `cover.jpg`), занятость по обоим именам; WebP и картинка шире 1100 px преобразуются всегда, порог выигрыша
   к ним не применяется; сбой одной картинки (пределы, повреждение) — «человеку» с причиной, остальные
   обрабатываются; оставленная порогом картинка — причина `выигрышМал` с весом было / лучший кандидат;
   анимированный PNG/WebP — «оставлено: анимация»; `проверить()` сверяет фактическую карту имён из применения.
5. Закрыты дефекты августовской проверки: байты обложки под своим расширением; прозрачность по пикселям, а не
   `hasAlpha`; возврат исходника не только для замены; поведение без `sharp`. Проверочный случай — фото, заранее
   сведённое к 256 цветам.
6. `scripts/image-prep.py` редактором больше не используется (скрипт не удаляется). `BUSINESS.md` Б10 п.3 и канон
   медиа приведены к решению.
