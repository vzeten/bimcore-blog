# Короткий отчёт владельцу

Отчёт нужен только для живой пробы. Он не пересказывает работу, тесты, файлы и круги проверки.
Claude сначала записывает тот же текст в `editor/.coordination/handoff.md`, затем показывает владельцу.

Не больше десяти строк и только три части:

```text
Результат: <что теперь должно работать для человека>.

Проверка: <не больше трёх действий в окне и ожидаемый результат>.

Ограничение: <только реальное известное ограничение текущего результата либо «нет»>.
```

Владелец отвечает верхнеуровневому Codex свободным текстом: что проверил, что получилось и что
смущает. От него не требуется повторять отчёт Claude или читать технические доказательства.

После живой пробы функциональные файлы не меняются без новой пробы. Claude поимённо готовит индекс.
Верхнеуровневый Codex читает handoff, `git diff --cached`, полный `git status --short`, `HEAD` и
`git write-tree`. Если поведение принято и блокеров нет, он пишет
`APPROVED_TO_COMMIT head=<sha> tree=<hash>`. Claude коммитит без повторного вопроса владельцу только
при неизменных `HEAD` и хеше дерева.
Настоящая публикация статьи и разрушительные действия по-прежнему требуют явного подтверждения.
