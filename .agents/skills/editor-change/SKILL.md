# Одна операция

Прочитать `editor/CURRENT_TASK.md` и относящиеся к действию разделы
[действующего процесса](../../../editor/TASKS.md#действующий-процесс).
Перед новой или расширенной операцией вызвать менеджера по editor/process/task-manager.md.
Менеджер выбирает работу, Codex оформляет контракт; Claude пишет код и сверяет папку/Git.
Критерии результата и точка остановки берутся из контракта, проверки — из класса риска TASKS.
Запуск и статусы `run-status.json`, включая `ready_for_review`, — раздел «Передача между чатами и
сессиями» в `editor/TASKS.md`.
