# Живая проверка

Claude перед владельцем проходит ровно изменённый сценарий на `localhost:4780`, проверяет экран и,
если операция пишет данные, итоговый файл. Следы пробы убираются, чужие черновики не трогаются.

Владельцу показывается короткая инструкция из `editor/REPORT.md`. Владелец сообщает наблюдения
верхнеуровневому Codex свободным текстом. Эта проба идёт после технических проверок и до
подготовки точного снимка коммита.
