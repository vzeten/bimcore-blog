# Живая проверка

Claude до контрольного коммита сам проходит ровно изменённый сценарий на `localhost:4780`, проверяет
экран и, если операция пишет данные, итоговый файл. Следы пробы убираются, чужие черновики не
трогаются. После чистого контрольного коммита и `GO` технического контролёра верхнеуровневый Codex
даёт владельцу короткую проверку точного `HEAD`.

Владельцу показывается короткая инструкция из `editor/REPORT.md`. Владелец сообщает наблюдения
верхнеуровневому Codex свободным текстом. Новый функциональный коммит аннулирует технический итог и
пробу изменённого сценария.
