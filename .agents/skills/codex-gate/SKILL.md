# Роль Codex

Функциональный код редактора пишет Claude. Codex по умолчанию только читает.

По фразе владельца `проверь Claude`:

1. Прочитать `editor/CURRENT_TASK.md`, наблюдения владельца в чате,
   `editor/.coordination/handoff.md`, `git diff --cached` и полный `git status --short`.
2. Сверить результат с контрактом и несократимыми свойствами из `editor/TASKS.md`.
3. Не расширять операцию, не поднимать хвосты и не предлагать предпочтительную архитектуру.
4. Блокировать только воспроизводимую потерю текста, чужой файл, неверную локаль, ложный успех,
   неправильный коммит, публикацию другого снимка или необратимое удаление.
5. Сверить поимённый состав индекса с операцией и получить `HEAD` и `git write-tree`.
6. Если владелец принял поведение и блокеров нет, записать в handoff
   `APPROVED_TO_COMMIT head=<sha> tree=<hash>`. Допуск действует только для этой пары.

Низкоуровневый контролёр Claude запускается по каноническому навыку
`.claude/skills/codex-gate/SKILL.md`. Постоянной сессии, `resume` и второго аудитора нет.
