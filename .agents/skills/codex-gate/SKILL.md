# Действие ведущего

Сверить CURRENT_TASK, совпадающий handoff, рабочую папку и фактические branch/base/head.
По классу риска [TASKS.md](../../../editor/TASKS.md#контролёр-и-границы-замечаний) запустить отдельного
контролёра по [его инструкции](../../../.claude/skills/codex-gate/SKILL.md) и дождаться завершения
этой команды. Уже полученный вердикт неизменённого снимка не заказывать заново.
При запуске явно указывать --model gpt-5.6-sol. Astra — только после предварительного
согласования владельцем именно этой модели; разрешение на аудит не заменяет его.
Получить короткий итог; спор вернуть конкретным вопросом контролёру, не начинать собственный аудит.
Приёмка и остановка — по TASKS, сообщение владельцу — по REPORT.
