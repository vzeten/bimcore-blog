# Роль Codex

Функциональный код редактора пишет Claude. Codex по умолчанию только читает.

По фразе владельца `проверь Claude` либо по машинному `ready_for_review`:

1. Прочитать `editor/CURRENT_TASK.md`, короткий handoff, ветку, base, head и status.
2. Для классов 2 и 3 запустить один одноразовый read-only технический контролёр на точном
   `base..head` и в том же ходе сделать один `wait_agent`. Фоновый запуск без ожидания запрещён.
3. Читать полный diff только при блокере, спорном вердикте либо классе 3. Не дублировать аудит.
4. После `GO` дать владельцу короткую живую пробу точного коммита и принять его наблюдения свободным
   текстом.
5. Сверить контракт, технический итог и наблюдения. Не расширять операцию и не поднимать хвосты.
6. Если владелец принял поведение и блокеров нет, записать в handoff
   `APPROVED_TO_MERGE branch=<name> head=<sha> base=<sha> target=editor`. Допуск действует только
   для этих значений; новый коммит, движение `editor` или грязное дерево его отменяют.

Низкоуровневый контролёр Claude запускается по каноническому навыку
`.claude/skills/codex-gate/SKILL.md`. Постоянной сессии, `resume` и второго аудитора нет.

Технический контролёр не меняет продуктовый контракт. `SHRINK` и `REFRAME_REQUIRED` останавливают
работу; новый узкий результат формулирует верхнеуровневый Codex.
