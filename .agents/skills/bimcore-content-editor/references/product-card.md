# Карточка товара (ProductCard)

Компонент — `src/components/ProductCard.jsx`, зарегистрирован в `src/theme/MDXComponents.js`. Перед вставкой прочитать комментарий в начале компонента: если описание ниже и код расходятся, верен код, а расхождение назвать автору.

## Роль Learn и магазина

- Learn — инструкция: объясняет применение набора и ведёт на точную страницу товара.
- Магазины (адреса и способы оплаты — в `src/data/products.json`; основной — `bimcore.one`, для RU есть и магазин INT LINES) — единственный источник товарной разметки, цены, валюты и наличия.
- На Learn остаётся автоматическая разметка статьи. ProductCard не создаёт `Product`/`Offer` и не показывает цену.
- Роль карточки меняется согласованно во всех локалях.
- На языках из таблицы `оплата.языкиСВыбором` (`products.json`, сейчас RU) кнопка раскрывает выбор способа оплаты; выбор браузер запоминает для всех карточек сайта, его можно сменить. Других интерактивных функций нет.
- Карточка — не доказательство роста продаж; уместность в образовательной статье оценивать по [write-articles.md](write-articles.md).

## Где ставить

- Инструкция семейства (`guides/families/<slug>/`, EN/RU/ES): карточка вверху, сразу после шапки и импортов.
- Уроки и блог завершаются штатным CTA ([quality-standard.md](quality-standard.md), «FAQ и CTA»). Карточку в тело блога ставить только по решению владельца сайта (пример в репозитории — `blog/4-best-kitchen-layout-solutions/`).

## Свойства

| Свойство | Правило |
|---|---|
| `ecwidProductId` | Код товара, обязательный. Это ключ таблицы `src/data/products.json`; товара там нет — уточнить у владельца сайта |
| `guideButton` | Вторая кнопка «Состав набора», ведёт на инструкцию набора из таблицы. Только по смыслу статьи |
| `name` | Коммерческое название товара; не копировать title инструкции |
| `description` | Одно краткое локализованное предложение |
| `image` / `imageAlt` | Локальная картинка товара в папке своей локали и понятный alt |
| `buyUrl` | Только для товара, которого нет в таблице; иначе адрес берётся сам |

- Если `name`, `description`, `image`, `imageAlt` не заданы, они подтягиваются из карточки в инструкции набора на языке страницы. Записанное в статье важнее подтянутого: в самих инструкциях и для товаров без инструкции на этом языке их пишут явно.
- Надписи кнопок берутся из переводов сайта (`i18n/<язык>/code.json`); главная кнопка «Посмотреть цену в магазине». Свои надписи кнопок не задавать.
- Устаревшие свойства `eyebrow`, `shopLabel`, `shopUrl`, `buyLabel` не использовать. Свойства не придумывать.
- Картинка товара `product.<ext>` — своя копия у каждой локали, рядом с MDX или в локальной `img/`; ссылка на файл другой локали запрещена ([media.md](media.md)).

## Заголовок инструкции

Точное название предмета в начале, роль инструкции только в конце:
- EN: естественное название товара + `User Guide`;
- RU: прежнее название дословно + `. Инструкция`;
- ES: прежнее название дословно + `. Guía de uso`.

Название магазина не добавлять: Docusaurus сам дописывает `| BIMCORE Learn` во вкладку и SEO-заголовок.

## Шаги для новой инструкции

1. Найти код товара в `src/data/products.json`.
2. Положить свою копию `product.<ext>` в папку каждой локали.
3. Вставить `<ProductCard>` сразу после шапки.
4. Проверить сборку EN/RU/ES и итоговую страницу ([publish-and-check.md](publish-and-check.md)).

## Примеры

Инструкция набора (RU):

```mdx
import productPreview from './product.png';

<ProductCard
  name="Двери для Revit"
  description="Распашные, двойные, раздвижные и технические двери, проёмы и порталы."
  image={productPreview}
  imageAlt="Набор дверей для Revit"
  ecwidProductId="695706588"
/>
```

Короткая форма в статье, где данные подтягиваются из инструкции набора:

```mdx
<ProductCard ecwidProductId="543629545" guideButton />
```

В локализации карточки переводятся название, описание, alt; товар, код и картинка сохраняются ([localize.md](localize.md), «Испанские инструкции к семействам Revit»).
