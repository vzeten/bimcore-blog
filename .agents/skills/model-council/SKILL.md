# Совет моделей не является этапом процесса

Не вызывать совет автоматически из-за нового модуля, настройки, правки владельца или высокого
класса риска. Обычную техническую развилку решает Claude с низкоуровневым Codex-контролёром.

Совет допустим только когда:

1. два действующих продуктовых требования противоречат друг другу; или
2. два разных технических подхода не решили воспроизводимую корневую проблему.

Совет read-only. Он возвращает не больше трёх вариантов, обязательно ищет более простой путь и
отделяет техническое решение от выбора видимого поведения. Владельцу показывается один собранный
пакет только при `OWNER_REQUIRED`.
