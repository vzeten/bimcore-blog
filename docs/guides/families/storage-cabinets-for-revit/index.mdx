## 1. GENERAL INFORMATION

-   Set name: Storage cabinets
-   Version 1.0.0
-   Revit version: 2019

### Description

This set of Revit families is made for modeling storage cabinets/wardrobes in Autodesk Revit.

Using the families, you can create cabinets, doors, showcases, bookcases, cornice according to exact dimensions. Suitable for interior designers and architects. Families are not detailed enough for furniture makers.

### Loading and placing into the project

In order to view and download the families from the set, you can open **Project with storage cabinets** and copy the families using the Ctrl+C key combination, and then paste them into your project Ctrl+V.

Or open the folder with family files and drag it into the project with the mouse.

## 3. FAMILIES: PARAMETERS AND ELEMENTS

### Storage cabinet

**Storage cabinet** is used to build cabinets with drawers or top section.

![Storage Cabinets Revit Families — Storage cabinet](./img-02.png)

Here you can on/off the following elements:

-   Top
-   Drawers
-   Plinth
-   Opening
-   Doors top
-   Doors cabinet
-   Doors drawers
-   Symbol_Hangers (on top plan)
-   Symbol_X (on top plan)

#### Dimensions

![Storage Cabinets Revit Families — Dimensions](./img-03.png)

Cabinet height is a height parameter in which there are other small element heights if they are turned on (Plinth height, Drawers height, Cabinet door height, Top height).

There are gray parameters that cannot be controlled. But they are needed to understand the size calculations. For example, **Door width.** The parameter shows the width of the doors, as it is calculated by a formula based on the number of doors and the width of the cabinet itself.

If the doors are turned off, the carcass moves by the Doors thickness.

#### Number of doors

![Storage Cabinets Revit Families — Number of doors](./img-04.png)

The number of doors in the Storage cabinet can be from 1 to 4.

The numbers of the doors go in order from left to right, where D1 is the leftmost door, and D4 is the rightmost door. The Doors width is not parametric, but is calculated automatically.

#### Opening

![Storage Cabinets Revit Families — Opening](./img-05.png)

The main types of openings in this family are left opening and right opening. If you turn off Left opening (D_Left), then Right opening will automatically turn on for all visible doors in vertical.

When you need to show a different type of opening for a top section or drawer, turn on additional parameters. These are *Top up, Drawers down and Drawers pullout*. And for the main door (Cabinet door), left or right opening remains.

#### Options

![Storage Cabinets Revit Families — Options](./img-06.png)

Doors can be standard (simple, without milling) or framed.

The number of drawers in height can be from 1 and more, but you need to ensure that the dimensions are correct so that an error does not appear.

*Drawers at full width* - this parameter removes the division along the doors and extends the drawers to the full width of the cabinet.

![Storage Cabinets Revit Families — Materials](./img-07.png)

### Storage cabinet Attic

**Storage cabinet Attic** is used to build attic cabinets with drawers or top section. Typically these cabinets will have a beveled corner to match the slope of the roof.

![Storage Cabinets Revit Families — Storage cabinet Attic](./img-08.png)

Here you can on/off the following elements:

-   Top
-   Drawers
-   Plinth
-   Opening (on top plan)
-   Opening drawers
-   Doors top
-   Doors cabinet
-   Doors drawers
-   Symbol_Hangers (on top plan)
-   Symbol_X (on top plan)

#### Dimensions

![Storage Cabinets Revit Families — Dimensions](./img-09.png)

Cabinet height is a height parameter in which there are other small element heights if they are turned on (Plinth height, Drawers height, Cabinet door height, Top height).

Slope width starts from the top left point of the cabinet and increases to the right, and the Slope height - downwards.

There are gray parameters that cannot be controlled. But they are needed to understand the size calculations. For example, **D1_Width.** The parameter shows the width of the first door, as it is calculated by a formula based on the number of doors and the width of the cabinet itself. By default, all doors are equal to each other, because the corresponding parameter is enabled in the options.

If the doors are turned off, the carcass moves by the Doors thickness.

#### Number of doors

![Storage Cabinets Revit Families — Number of doors](./img-10.png)

The number of doors can be from 1 to 4.

The numbers of the doors go in order from left to right, where D1 is the leftmost door, and D4 is the rightmost door. The Doors width is not parametric, but is calculated automatically.

#### Opening

![Storage Cabinets Revit Families — Opening](./img-11.png)

Only drawers have opening on the doors (Opening drawers). And Opening is precisely opening on the plan from top.

You can select Left or Right opening. If you turn off Left opening (D_Left), then Right opening will automatically turn on for all visible doors in vertical.

When mirroring, the openings are also mirrored, so the names will be opposite: Left will become Right and so on.

#### Options

![Storage Cabinets Revit Families — Options](./img-12.png)

Doors can be standard (simple, without milling) or framed.

Doors outside are the doors that cover the cabinet carcass, and Doors inside, on the contrary, show the carcass thickness of the cabinet along the perimeter.

When the Doors are equal in width parameter is enabled - D1_Width is equal to the width of all other facades. If off, the width of each door (except D1.Width) is set manually.

The number of drawers in height can be from 1 and more, but you need to ensure that the dimensions are correct so that an error does not appear.

*Drawers at full width* - this parameter removes the division along the doors and extends the drawers to the full width of the cabinet.

![Storage Cabinets Revit Families — Common. Handles](./img-36.jpg)

-   Knob
-   D-shape
-   Т-shape
-   Profile pull

-   Leather
-   Leather D-shape

For the D-shape, T-shape and Profile pull handles works parameter Handle length.

![Storage Cabinets Revit Families — Common. Handles](./img-37.png)

The **T-shape** display changes with different handle lengths (Handle.Length).

#### Common. Handles placement

![Storage Cabinets Revit Families — Common. Handles placement](./img-38.png)

The placement of handles is not made by a drop-down list, but simply by numbers from 1 to 9. Visually, this is similar to the placement of numbers from a keyboard. You can also look at the tooltip in the **Handle placement** parameter itself.

The position of the handles can be horizontal or vertical. The **Handle horizontally** parameter is responsible for this.

#### Common. Opening

![Storage Cabinets Revit Families — Common. Opening](./img-39.png)

-   Right Slide

-   Lift up
-   Lift oblique
-   Folder

Doors opening does not depend on the handles position.

![Storage Cabinets Revit Families — Common. Dimensions](./img-40.png)

Door frame inside - the frame is inside, behind the glass.

#### Door Wave

Door Wave - a door with milling, similar in shape to a wave.

![Storage Cabinets Revit Families — Door Wave](./img-43.jpg)

The width of the groove and tongue are adjustable, only the tongue will have an approximate width. This is due to the specific way that arrays work in Revit.

#### Door Ribbed-square

Door Ribbed-square  - a door with milling, similar in shape to slats.

![Storage Cabinets Revit Families — Door Ribbed-square](./img-44.jpg)

The width of the groove and tongue are adjustable, only the tongue will have an approximate width. This is due to the specific way that arrays work in Revit.

Unlike other milling families, the groove depth is adjustable.

#### Door Ribbed-round

Door Ribbed-round - a door with milling, similar in shape to rounded slats.

![Storage Cabinets Revit Families — Door Ribbed-round](./img-45.jpg)

The width of the groove and tongue are adjustable, only the groove will have an approximate width. This is due to the specific way that arrays work in Revit.

#### Door Glass

Door Glass - a door with glass, muntins and muntins in the form of a cross.

Muntins - these are dividing planks on the door.

![Storage Cabinets Revit Families — Door Glass](./img-46.jpg)

#### Door Classic

Door classic - framed doors with complex milling. The profile can be changed inside the family, but with a large profile width there may be errors in work.

![Storage Cabinets Revit Families — Door Classic](./img-47.jpg)

![Storage Cabinets Revit Families — Door Classic](./img-48.jpg)

When the Door height is less than 150 mm, all types of door become Type 1. And the door frame width at the top and bottom is 2 times less, unlike the side frames.

When the Door height is less than 100 mm, all types of door become a simple rectangular facade without milling.

The Door width cannot be less than 150mm.

#### Door Louvers

Door louvers - a door with vertical and horizontal lamellas.

![Storage Cabinets Revit Families — Door Louvers](./img-49.jpg)
