## 1. GENERAL INFORMATION

-   Set name: Bathroom
-   Version  1.3.0
-   Revit version: 2019

### Description

This set of Revit families is designed for modeling bathroom in Autodesk Revit, suitable for BIM projects in interiors and architecture. The library includes parametric families of plumbing equipment, developed with precise dimensions and requirements for designing bathrooms and laundry rooms.

Using these families, you can create and customize bathtubs, sinks, shower enclosures, shower systems, faucets, towel warmers, plumbing fixtures, and bathroom accessories.

The set is intended for interior designers and architects working in Autodesk Revit on residential and commercial projects.

### Loading and placing into the project

In order to view and download the families from the set, you can open **Project with Bathroom** and copy the families using the Ctrl+C key combination, and then paste them into your project Ctrl+V.

Or open the folder with family files and drag it into the project with the mouse.

## 3. FAMILIES: PARAMETERS AND ELEMENTS

### Outputs symbol

![Bathroom Revit Families — Outputs symbol](./img-13.png)

At **medium** detail level in the top view, you can enable the graphic symbol (GS) for water connections to indicate which pipes need to be routed to this area.

To enable the Graphic symbol, follow these steps:

1.  In the Properties, under the **Graphics** grouping, check the visibility parameter "**Graphic symbol**".
2.  Change the view detail level to **Medium**.

![Bathroom Revit Families — Outputs symbol](./img-14.png)

Graphic symbol display in the top view depends on which systems are enabled in the Graphics parameters within the parent family for Graphic symbol, as well as the "Vertical placement" parameter.

Graphic Symbols by system type:

-   Blue - Cold water
-   Red - Hot water
-   Green - Drain

![Bathroom Revit Families — Outputs symbol](./img-15.png)

In the front view, Outputs symbol in families are shown as circular markers with centerlines.

Marker colors also indicate the system type.

Graphic symbol display depends on enabled system type parameters and the "Vertical placement" parameter.

### Graphic Symbol Outputs. General Dimensions

![Bathroom Revit Families — Graphic Symbol Outputs. General Dimensions](./img-16.png)

In the **Graphic symbol** subgroup under the **Dimensions** grouping, parameters control the size and position of the graphic symbol relative to elements in the parent family.

Graphic Symbol parameters found in families:

-   GS_CW and HW height: Cold and Hot water outlet height
-   GS_Drain height: Drain outlet height
-   GS_CW and HW diameter: Graphic Symbol cold/hot water circle diameter
-   GS_Drain diameter: Graphic symbol drain circle diameter
-   Axis displacement CW: Cold Water outlet offset (or cold/hot Water) from drain

#### Connectors

![Bathroom Revit Families — Connectors](./img-17.png)

Some families include connectors to cold water, hot water, and drainage.

Connector dimensions can be specified using the following parameters:

-   Connector CW diameter
-   Connector CW and HW diameter
-   Connector Drain diameter

-   F_Placement on the plane

-   F_Wall-mounted placement

For the **built-in sink**, option "F_Placement on the sink" is available only with "Placement on a countertop".

##### Dimensions

![Bathroom Revit Families — Dimensions](./img-75.png)

Dimensions are controlled by parameters "INT_Width" and "INT_Depth".

Parameter "Faucet offset from the sink" controls the distance from the faucet axis to the sink edge only for options "F_Placement on the plane" and "F_Wall-mounted placement".

***Important**: In the sink family, the parameter "Edge width" is named "Edge thickness".

![Bathroom Revit Families — Dimensions](./img-76.png)

Dimensions are controlled by the parameter "INT_Height".

Parameter "Wall-mounted faucet vertical shift" - distance from sink top to faucet axis (available when "Faucet" parameter is enabled and "F_Wall-mounted placement" option is selected).

Parameter "Siphon offset downward from the sink" - distance from sink top to siphon horizontal axis.

Parameter "Siphon offset to the wall" - distance from wall surface to siphon vertical axis.

Siphon placement parameters are available when "Siphon" parameter is enabled.

##### Pedestal dimensions

![Bathroom Revit Families — Pedestal dimensions](./img-77.png)

For Wall-hung sink and Corner sink, pedestal dimensions can be changed.

Parameter "Pedestal height" sets the vertical dimension from the top sink connection point to the pedestal base.

Parameter "Pedestal width from top (Pedestal top depth)" sets the width (depth) of the pedestal at the top (sink connection area).

"Pedestal width from bottom (Pedestal depth from below)" sets the width (depth) of the pedestal at the bottom (base).

These parameters create the pedestal's trapezoidal geometry.
