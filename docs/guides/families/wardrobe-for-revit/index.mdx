## 1. GENERAL INFORMATION

-   Set name: Wardrobe
-   Version 1.2.0
-   Revit version: 2019

### Description

This set of Revit families is made for modeling wardrobes in Autodesk Revit.

Using the families, you can create frame systems, cabinet systems, dressers and  and individual internal components according to exact dimensionss.

Suitable for interior designers and architects.

### Loading and placing into the project

In order to view and download the families from the set, you can open Project with wardrobe and copy the families using the Ctrl+C key combination, and then paste them into your project Ctrl+V.

Or open the folder with family files and drag it into the project with the mouse.

The set includes families in the Furniture and Entourage categories.

## 3. COMMON ELEMENTS

Common elements are elements that are frequently repeated within families.

### Handles

Handles are included in families with doors. These families are:

-   Double sliding door
-   Double swing door
-   Single swing door
-   Triple sliding door
-   Swing-door cabinet
-   Cabinet system

And also in families with fronts:

-   Pull-out trouser rack
-   Drawer
-   Dresser
-   Section Shelf_Crossbar_Dresser
-   Section 3 shelves and dresser
-   SECTION_3 LEV

The required handle type can be selected from the Handle Type drop-down list. The following handle types are included in the set:

-   Round knob
-   Surface-mounted handle
-   U-handle
-   T-handle
-   Recessed handle (this type is selected in the panel type)

![Wardrobe Revit Families — Handles](./img-04.jpg)

Families with doors:

-   Cabinet system
-   Swing-door cabinet
-   Single swing door
-   Double swing door
-   Double sliding door
-   Triple sliding door

In these families, the handle position is controlled by the “Handle offset” and “Vertical handle offset” parameters.

The handle size is defined by the “Handle Length” parameter.

![Wardrobe Revit Families — Handles](./img-05.jpg)

The handle can be horizontal or vertical.

![Wardrobe Revit Families — Handles](./img-06.jpg)

For single doors, the position is set using numbers from 1 to 9 — analogous to the layout of numbers on a numeric keypad (see the tooltip in the “Handle Position” / “Single Door Handle Position” parameter).

For double and triple doors, the handle position on the panel is specified as follows: 1 — bottom, 2 — middle, 3 — top (see the tooltip in the “Handle Position” parameter).

![Wardrobe Revit Families — Handles](./img-07.jpg)

In families with fronts:

-   Dresser
-   Drawer
-   Pull-out trouser rack

The handle can only be horizontal.

Its position is controlled by the Moving the handle down parameter, and the size is defined by the Handle Length parameter.

Section families are simplified; in them, only the handle length can be specified, without any offset.

![Wardrobe Revit Families — Handles](./img-08.jpg)

The following options are provided: Pull out the trouser rack and pull out the trouser rack halfway, toggle the front on or off, and enable/disable the Conventional graphic symbol - Opening.
