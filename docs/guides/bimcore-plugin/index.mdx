The BIMCORE plugin panel shows the INT LINES family sets you've purchased. Each set has an **Open** button to open the set's Revit project. Each family in the set's list has an **Insert** button to place the family in your own Revit project.

Free families are available in a separate set called **Free families**.

## Get started

1. [Install the BIMCORE plugin and open it in Revit](/guides/bimcore-plugin/installation).
2. [Register and sign in to the BIMCORE plugin](/guides/bimcore-plugin/sign-in) using the password sent by email.
3. [Open a set's project and insert a family](/guides/bimcore-plugin/sets).
4. [Find a family, view set information and choose a language](/guides/bimcore-plugin/panel).

If your sets are missing from the panel, you need to update the plugin or you've forgotten your password, see the [BIMCORE plugin FAQ](/guides/bimcore-plugin/faq).

Read about plugin updates in [What's new](/guides/bimcore-plugin/whats-new).
