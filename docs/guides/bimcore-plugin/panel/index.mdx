## Find a set or family

1. In the plugin window, enter a set or family name in **Search**.

## View set details

1. In the plugin window, click the **i** icon to the right of a set.
2. **Set Information** opens, showing **Instructions**, **Chat**, **Projects**, **Families (version in project)** and **Versions history**.

## Change the content language

1. On Revit's **Add-Ins** tab, click **Settings**.
2. The **User settings** window opens.
3. In **User settings**, select **Русский** or **English** under **Content language**.
