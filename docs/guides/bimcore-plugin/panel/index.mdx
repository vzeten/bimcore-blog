The plugin panel has a **Search** field and an **i** icon for each set. Use **Search** to find a set or family by name. The **i** icon opens **Set Information**, which contains the **Chat** and **Instructions** buttons and the **Projects**, **Families (version in project)** and **Versions history** sections.

In **User settings**, the **Content language:** field lets you choose Russian or English for your families.

## Find a set or family

In the plugin panel, enter the set or family name in **Search**.

![Search field in the BIMCORE plugin panel](./img-10.png)

## Open Set Information

In the plugin panel, click the **i** icon in the upper-right corner of the set you want to check.

![Set Information window](./img-11.png)

## Choose the family language

If the sets haven't been downloaded in your chosen language, the plugin will display a warning. Downloading starts after you click **OK**.

1. In Revit, click **Settings** on the **Add-Ins** tab.
2. In **User settings**, select **Russian** or **English** in **Content language:** and click **OK**.

   ![Content language field in the User settings window](./img-09.png)
