## 1. Close Revit

1. Save each open Revit project.
2. Close Revit.

## 2. Download the installer

1. Click [Download the BIMCORE plugin installer](https://revitcontentstorage.blob.core.windows.net/0-plugin-installers/bimcore.msi?sv=2023-01-03&st=2024-09-16T16%3A53%3A23Z&se=9999-09-17T16%3A53%3A00Z&sr=b&sp=r&sig=oVopKFMhyna0ItUuDXP4UNoV%2FNRg8KyIN9uv4z7Zk0M%3D).
2. The downloaded bimcore.msi file appears in your browser's download list.

## 3. Install the plugin

1. Open bimcore.msi from your browser's download list.
2. If Windows displays "Windows protected your PC", click **More info** in that window.
3. If that warning appears, click **Run anyway** in the same window.
4. If the installer displays a window listing Autodesk Revit, check for any Revit windows still open and close them.
5. If that window appears, click **OK** after closing Revit.
6. Wait for the installer window to close.

## 4. Open the plugin in Revit

1. Start Revit.
2. If Revit displays **Security - Unsigned Add-In**, click **Always Load** in that dialog.
3. In Revit, select the **Add-Ins** tab.
4. On the **Add-Ins** tab, click **Panel**.

![Add-Ins tab and the Panel button](./img-06.png)

5. The plugin window opens.
