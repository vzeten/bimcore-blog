## Version 26.10.23.2

Released on October 23, 2026.

### Performance and stability

- Reduced the delay caused by loading the plugin when Revit starts.
- Fixed installation, sign-in and registration errors affecting some users.
- Fixed file download errors.
- Made family downloads faster. Added support for resuming interrupted downloads and switching between servers when connection problems occur.
- Reduced the total time needed to insert a family for the first time and the delay after canceling the operation.
- Made refreshing the list of sets and switching to a language that has already been downloaded faster.
- Made search faster. It is now case-insensitive and treats “е” and “ё” as the same letter.

### Interface and usability

- Added the ability to expand a set and view its families directly in the list.
- Added download progress and an estimate of the time remaining.
- Made switching between the **Sets** and **Families** tabs clearer.
- The search field now clears when you switch tabs.
