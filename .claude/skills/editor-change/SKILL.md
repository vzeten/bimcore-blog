# Одна правка редактора

До функционального кода прочитать `editor/CURRENT_TASK.md`, относящиеся к операции части
`editor/BUSINESS.md`, `editor/SPEC.md` и карту модулей. Выбрать класс 1, 2 или 3 строго по
`editor/TASKS.md`.

До первой правки проверить записанные в `CURRENT_TASK.md` базовый коммит и рабочую ветку. Новую
возможность писать только в локальной `feature/editor-<суть>`, дефект — в `fix/editor-<суть>`;
прямо в `main` функциональный код не писать. Если сессия продолжает начатую операцию, сначала
сверить текущую ветку и фактический Git с карточкой.

В начале видимой рабочей сессии проверить, что Codex уже записал в
`editor/.coordination/run-status.json` точные operation, branch, base, текущий `HEAD`, target,
`state=running` и время. Перед итоговым ответом заменить состояние конечным. Stop-hook статус
не меняет: он срабатывает в конце одного хода, а не при закрытии процесса Claude.

- Класс 1: правка и один проход изменённого экрана; Codex не вызывать.
- Класс 2: до кода контролёр нужен только при новой общей границе хранения, публикации, Git,
  удаления, внешнего сервиса или секретов.
- Класс 3: до кода вызвать непостоянного контролёра по `codex-gate`.
- Не менять соседние функции. Рост объёма означает уменьшение операции, а не новый слой.
- `SHRINK` и `REFRAME_REQUIRED` означают остановку: описать расхождение в handoff и ждать нового
  контракта. Самостоятельно выбрасывать часть результата запрещено.
- Ограничение строк — сигнал остановиться и переформулировать задачу, а не цель, которую можно
  выполнить минификацией, объединением несвязанных частей или удалением полезных проверок.
- После кода выполнить только проверки своего класса и подготовить короткий handoff.
- После законченной смысловой части и перед остановкой сессии сделать локальный контрольный коммит.
  Отдельного согласия владельца для него не нужно; push рабочей ветки без прямого слова запрещён.
- После чистого контрольного коммита записать `ready_for_review` и точный `HEAD` в
  `editor/.coordination/run-status.json`. `done` и фраза в handoff не являются сигналом завершения.
- Перед переключением ветки остановить сервер и не оставлять незакоммиченных изменений. Принятие,
  отказ и синхронизация с изменившимся `main` выполняются по `editor/TASKS.md`.

Функциональный код пишет Claude в одной видимой рабочей сессии операции. Одноразовый скрытый запуск
Claude вместо неё запрещён. Codex без прямой просьбы владельца файлы редактора не меняет.
