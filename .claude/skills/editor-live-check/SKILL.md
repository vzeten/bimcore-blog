# Живая проба

Claude выбирает [экземпляр для живой пробы](../../../editor/TASKS.md#экземпляр-для-живой-пробы)
и проверяет изменённый сценарий и результат записи на копии статьи, не трогая живой контент.
После `GO` итогового контролёра (класс 1 — без контролёра) верхний Codex даёт владельцу пробу
точной версии по [REPORT.md](../../../editor/REPORT.md).
Границы приёмки, остановка и новые замечания — по [TASKS.md](../../../editor/TASKS.md#как-выполняется-одна-операция).
Технические прогоны исполнителя верхний Codex повторно не выполняет.
