# Живая проверка

Claude до контрольного коммита сам проходит ровно изменённый сценарий на `localhost:4780`, проверяет
экран и, если операция пишет данные, итоговый файл. Следы пробы убираются, чужие черновики не
трогаются. Затем Claude делает контрольный коммит, оставляет дерево чистым и завершает работу со
статусом `ready_for_review`.

После `GO` итогового контролёра владельцу показывается короткая инструкция из `editor/REPORT.md` для
точного `HEAD`. Владелец сообщает наблюдения верхнеуровневому Codex свободным текстом. Новый
функциональный коммит аннулирует технический итог и пробу изменённого сценария.
