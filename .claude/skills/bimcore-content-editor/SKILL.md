# Подключение общего навыка BIMCORE

0. Для существующей статьи сначала `GET http://localhost:4780/api/comments?path=<путь статьи>` и ответить в каждой открытой нити владельца (`вид: 'замечание'`, `состояние: 'открыто'`; ответ — `действие: 'ответить'`). Только потом правки, каждая со своей нитью «правка». Порядок — раздел «Комментарии в редакторе» в `.agents/skills/bimcore-content-editor/references/publish-and-check.md`.

Перед любым действием полностью прочитай и выполни канонический навык проекта:

`../../../.agents/skills/bimcore-content-editor/SKILL.md`

Все упомянутые там относительные ссылки разрешай от папки канонического навыка `.agents/skills/bimcore-content-editor/`. Этот файл только подключает общий источник правил для Claude и не заменяет его.
