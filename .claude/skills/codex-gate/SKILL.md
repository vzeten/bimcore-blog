# Технический контролёр

Когда вызывать и кто ждёт — [TASKS.md](../../../editor/TASKS.md#контролёр-и-границы-замечаний).
Запуск в PowerShell — одной командой с конечным вводом, без PTY (`tty: false`):
```powershell
Get-Content -LiteralPath $promptFile -Raw -Encoding utf8 | & $codexExe exec --model gpt-5.6-sol --ephemeral --sandbox read-only --color never -C $worktree -
if ($LASTEXITCODE -ne 0) { throw "Контролёр завершился с кодом $LASTEXITCODE; технический вердикт не получен" }
```
`$promptFile` — сохранённое задание, `$codexExe` — путь к установленному Codex,
`$worktree` — проверяемая рабочая папка. До запуска проверить, что задание непустое.
Конвейер закрывает stdin после передачи задания. Не заменять закрытие ввода символами
Ctrl+Z/Ctrl+D через `write_stdin`: в PTY они могут оставить контролёра ждать ввод.
Ошибка запуска или сервиса (например, HTTP 503) не является техническим вердиктом;
не ждать завершения Claude повторно и не считать молчание контролёра работой над кодом.
Модель задавать явно. Astra — только после предварительного согласования владельца по TASKS;
разрешение на проверку не разрешает Astra, автоматической замены Sol на Astra нет.
Промпт явно задаёт роль технического контролёра: без Obsidian, без записи и без контакта с владельцем.
Исполнитель передаёт только результат/границы/приёмку, относящиеся технические свойства,
рабочую папку, branch/base/head и ссылки на доказательства. История чата и будущий план не нужны.

Сверить снимок и цель. Искать воспроизводимую потерю данных, чужой файл или локаль, ложный успех,
неправильную публикацию и невозможность выполнить согласованный сценарий.
Замечание содержит конкретное место, шаги и ущерб. Стиль, любимая архитектура и гипотетическое
будущее не блокируют. Лишние части назвать только при обнаружении, отдельного аудита упрощения нет.
Контролёр не меняет контракт. Повтор после исправления ограничен замечанием и затронутыми свойствами.

Ответ:
```text
Снимок: <branch base head, чистота>
Вердикт: GO | SHRINK | BLOCK_REAL_RISK
Размер: <рабочий код и тесты +/- строк, новые файлы>
Блокеры:
- <до трёх или «нет»>
Убрать:
- <до трёх или «ничего»>
Остаточный риск:
- <что остаётся для живой пробы>
```
