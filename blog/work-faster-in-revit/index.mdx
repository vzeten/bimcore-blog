Most of your time in Revit goes into finding families and reworking them. Next
come setting up a new project from scratch and configuring the graphics of every
view again. Below are ten ways to speed up your work in Revit.

## 1. Get a ready family library

Finding families and adapting them eats more design time than anything else. You
download a sofa and it turns out to be a 30 MB mesh. You find a wardrobe with no
usable dimensions. You model a kitchen yourself and it lands in the schedule as a
generic model. Each of these rounds costs hours, and it repeats on every project.

A tested library closes that loop. Parametric families flex to real dimensions,
sit in the correct categories and count properly in schedules.

Full disclosure: this is what we do. We built a complete family library for
interior designers, and it lives at [bimcore.one](https://bimcore.one/).

If you are still working with free content, read our roundup of
[30 sites with free Revit families](/blog/free-revit-family-websites). It
collects the best sources and shows how to check a file before it enters a
project.

## 2. Work from a specialised project template

The default Revit template gives you an empty file. An interior template gives
you materials, annotation styles, view templates, sheet layout and schedules that
are already set up for interior work. What remains is learning Revit itself and
drawing.

A library together with a template produces the largest jump in speed, because
there is nothing left to configure. Ours lives
[in the shop](https://bimcore.one/products/revit-interior-design-template).

Building your own works too. Two or three hours once, then the file lives in a
known folder, gets versioned by date and grows every time you catch yourself
repeating a setup step. For a project already under way, **Manage** and then
**Transfer Project Standards** brings settings from another open file. It does
not carry legend views, so legends still have to be copied by hand.

## 3. Set up view templates

On a multi-storey building this is not optional. Without templates you configure
the first floor plan, then repeat the same twenty settings on the second, then on
the third.

A view template stores detail level, scale, visibility, filters and graphic
overrides. Apply it to the next floor and the view matches. Edit the template and
every view using it updates at once.

For an interior project a small set covers almost everything: furniture plan,
finishes plan, reflected ceiling plan, interior elevations and a working 3D view.

## 4. Build your own keyboard shortcuts

You set them up once and the speed keeps growing, because hands memorise
combinations faster than heads do.

Type **KS** or go to **View**, **User Interface**, **Keyboard Shortcuts**. Assign
two-letter combinations to the commands you use dozens of times a day, and keep
them near your left hand so the right stays on the mouse.

The step most people skip: export the shortcuts to XML before you upgrade. The
file lives in `%APPDATA%\Autodesk\Revit\<release>` and imports into the next
version, so a layout learned once stays with you for years.

## 5. Learn four commands that speed up drawing

**Create Similar.** Right-click a configured element and pick Create Similar;
Revit starts placing the same type with the same settings. The button also sits on
the **Modify** tab, **Create** panel.

**Match Type Properties.** **Modify** tab, **Clipboard** panel, shortcut MA. The
cursor turns into a brush: click the source element, then click the ones that
should match it. This is the fastest way to tidy up near-identical types before
they multiply.

**Select All Instances.** Right-click an element, or a family type in the project
browser, then choose Visible in View or In Entire Project. Combined with the
Properties palette it edits hundreds of elements in one move.

**Tab.** Hover and cycle through the candidates under the cursor, so you stop
zooming in to select the right thing. Tab also picks up chains of connected
elements.

## 6. Fill your data in schedules

Filling parameters in a schedule is easier than doing it in plans, and missing an
element is much harder. Every row is visible at once, an empty cell stands out,
and you never look for elements on screen.

A schedule shows live model data, so typing in a cell changes the element itself.
Sort by the column you are cleaning up and work top to bottom. Deleting a row
deletes elements, so treat the table with the same care as a drawing.

## 7. Colour elements with filters

A filter sets display rules for every element that matches a condition. It works
inside a view template and on a single view.

A simple working example: walls coloured by type, so a plan shows at a glance
what is structural, what is a partition and what is a lining. The rule is written
once and the graphics follow the model, which means no manual overrides to find
and redo after each design change.

This takes an understanding of Revit above beginner level, and it pays back
accordingly. One habit worth building early: add a filter that catches elements
with no parameter value. That way you find the gaps before your client does.

## 8. Put colour schemes on room plans

A colour scheme works for rooms, areas and spaces. It colours a plan by parameter
value and keeps the legend for you.

The real convenience is elsewhere: add a new room and the scheme gives it the
next colour in order, with no manual recolouring. For space planning and zoning
drawings this is the quickest way to show the structure of a project.

## 9. Install pyRevit

pyRevit is free and adds a lot of tools. Two of them get used most. One builds a
hatch pattern out of drawn lines, so your own pattern takes a minute instead of a
session with a text file. The other colours the tabs of open views, so you find
the right view by eye in a second.

It installs from [pyrevitlabs](https://pyrevitlabs.io/) with an ordinary
installer, sits in your user profile and appears as its own ribbon tab. Nothing
about it requires programming.

## 10. Build a key schedule

This tool takes effort to understand and comes up rarely. In return it saves a lot
of time whenever one type of room or element needs a whole set of parameters
assigned at once.

A key schedule holds ready-made sets of values. You create a row per room type,
fill in floor, wall, skirting and ceiling finishes once, and in the room schedule
you only pick the key. Every parameter behind it fills itself, and editing the key
updates every room carrying it.

Create it from **View**, **Schedules**, **Schedule/Quantities**, choose the
category and switch the schedule type to keys. Shared parameters work inside key
schedules from Revit 2022 onwards, which widened what you can drive this way.

## One more thing, if you issue sheet sets

Revit exports PDF natively since the 2022 release, and the part worth setting up
is the naming rule. Build the file name from sheet number, sheet name and
revision, save the export setup, and every issue comes out named correctly
without a single manual rename.

## What to do first if you only have an hour

1. Assign shortcuts to your ten most used commands and export the XML.
2. Build view templates for the views you actually issue.
3. Learn Create Similar, Match Type Properties and Select All Instances.
4. Install pyRevit and pick two tools from it.

A library and a template need a decision and a budget, so leave those for a quiet
evening.

problem with different fixes. It has its own article:

## FAQ

### What pays off faster, a family library or a project template?

The library, if you draw a lot of furniture and equipment. The template, if every
new project starts with the same setup work. Together they give the largest jump,
because after buying both there is nothing left to configure.

### What is the difference between a project template and a view template?

A project template is the starting file: materials, families, sheets, settings. A
view template is a set of graphic settings applied to views inside a project. You
usually keep your view templates inside your project template.

### Can I edit the model from a schedule?

Yes, a schedule is a live view of the model. Typing in a cell changes the element,
and deleting a row deletes elements, so treat it with the same care as a plan.

### Will filters slow my views down?

A reasonable set will not. Long filter lists with complex rules do add work to
every regeneration, which is why heavy filter stacks show up in discussions about
[slow Revit models](/blog/speed-up-revit).

### Is pyRevit safe to install on a work machine?

It is open source and widely used in offices, and it installs per user without
touching the Revit installation. If your firm manages add-ins centrally, ask your
BIM manager first, because that is a policy question rather than a technical one.
