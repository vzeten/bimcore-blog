To save time on Revit interior projects, prepare the parts your practice uses repeatedly. A family library provides adjustable objects, a reference project shows how to document them, and a project template supplies the view and schedule settings. Together, they reduce the setup work needed for each new project.

Start with the task that repeats before every issue. If a kitchen revision requires editing geometry inside several families, start with modules whose dimensions and configuration you can change through parameters. If several people produce different graphics for the same kind of plan, start with view templates.

<truncate />

## Prepare families for the next revision

When choosing furniture, check what will happen after a client changes the design. Can you adjust a cabinet's width, change its front and assign a project material? Will it still read clearly in plan? Which values will appear in a schedule?

For a practice that regularly designs interiors, the [BIMCORE full family set](https://bimcore.one/) brings kitchens, storage, furniture, doors and other interior elements into a library from one source. The benefit comes from reusing families your team has already configured and documented for its projects.

Try the library in a small room. Place several objects, change their dimensions and check a plan, an elevation and a schedule. Save useful types and agree which parameters everyone must complete. The library still needs this initial setup.

## Keep a reference project

A reference project shows a colleague what the finished work should look like. Choose a small completed interior that your practice can use internally. Make the relationship between tags and schedules clear, along with the furniture detail shown in plans and the scope of interior elevations.

Avoid copying an old project wholesale to start a new job. Old addresses, marks, materials and hidden views can travel with the drawing setup. Use the reference to understand and reuse proven arrangements, then start the new job from a prepared template.

## Build the template around your drawing set

A project template should contain the settings you need on most jobs. These might include view templates for furniture plans and interior elevations, schedule definitions, tags and sheet formatting.

Ask three questions. Which views does someone set up manually on every project? Which schedule fields do they add? Which graphic settings do they repeat? Prepare those parts first.

The [BIMCORE interior design template](https://bimcore.one/products/revit-interior-design-template) can provide a starting point. It is currently listed as Russian-only, so an English-speaking practice needs to allow for translation and adaptation. Compare its contents with your own deliverables before adopting it. Keep the completed reference project available alongside the template so colleagues can see how those settings work in a finished drawing set.

## Use in-place models where they make sense

**Model In-Place** can be useful for a unique, awkwardly shaped worktop or window sill. You can build the geometry beside the surrounding walls. If these elements repeat, change size and need consistent quantities, decide how you will obtain their count, length or area before modelling them.

In-place elements can appear in schedules when their categories and parameters support it. The difficulty is an inconsistent setup. One element may have a manually entered length, another only geometry, and another may combine a worktop with several other parts.

For repeated elements, consider a loadable family with clear dimensions and the data you need. Keep a unique form as an in-place model when appropriate, but verify how it is counted before issuing the drawings.

## Give the team a consistent revision check

After changing a cabinet's width, a colleague should know which views and schedule row to inspect. Agree a short check for common revisions.

| Change | Check before issue |
|---|---|
| Built-in wardrobe size | Recess, opening space, elevation and scheduled size |
| Front material | Model, finish annotation and relevant schedule data |
| Kitchen layout | Cabinets, appliances, outlets and plan dimensions |
| Door type | Opening, swing symbol, wall finish and schedule row |

Start with one room and improve the parts that required repeated family or drawing setup. For more general working methods, see [how to work faster in Revit](/blog/work-faster-in-revit/).

If the library is your first step, try the [kitchen families](/guides/families/kitchen-for-revit/) on an actual design task. Then consider which other categories in the full set your practice uses regularly.
