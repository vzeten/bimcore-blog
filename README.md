# bimcore-blog — сайт learn.bimcore.one

Исходники сайта [learn.bimcore.one](https://learn.bimcore.one) на [Docusaurus](https://docusaurus.io): статьи,
уроки и инструкции к семействам Revit на трёх языках (EN — основной, RU, ES).

## Что где лежит
- `blog/`, `docs/` — статьи и разделы на английском; `i18n/ru/…`, `i18n/es/…` — те же статьи на русском и испанском.
- `src/` — оформление и компоненты сайта (список штатных компонентов — `src/theme/MDXComponents.js`).
- `plugins/`, `scripts/`, `docusaurus.config.js`, `sidebars.js` — сборка, проверки и настройки.
- `static/` — общие файлы сайта (картинки, `robots.txt`, переадресации).
- `.agents/skills/bimcore-content-editor/` — правила написания статей (единственный источник).
- `AGENTS.md` — вход для любого ИИ-помощника; `CLAUDE.md` подключает его.

## Как статья попадает на сайт
Статьи пишут и публикуют в редакторе статей (отдельная закрытая программа, в этот репозиторий не входит):
кнопка «Опубликовать» отправляет ровно файлы статьи в ветку `main`, после чего GitHub Actions собирает сайт
(`.github/workflows/deploy.yml`) и выкладывает его на GitHub Pages. Прямой `git push` статей не используется.

## Ветки
- `main` — опубликованный сайт и статьи.
- `fix/site-…`, `feature/site-…` — временные ветки правок кода сайта; удаляются после переноса в `main`.
- `gh-pages` — старый результат сборки, не используется.

## Локальная проверка
Зависимости уже установлены в рабочей папке. `npm ci` удаляет и заново ставит пакеты — только с согласия
владельца (раздел «DANGEROUS» в `AGENTS.md`). Проверки:
```bash
npm run build
```
```bash
npm test
```
