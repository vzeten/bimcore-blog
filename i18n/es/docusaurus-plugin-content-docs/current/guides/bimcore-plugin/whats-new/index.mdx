## Versión 26.10.23.2

Publicada el 23 de octubre de 2026.

### Velocidad y estabilidad

- Hemos reducido la demora que provoca la carga del plugin al iniciar Revit.
- Hemos corregido errores de instalación, inicio de sesión y registro que afectaban a algunos usuarios.
- Hemos corregido errores en la descarga de archivos.
- Hemos acelerado la descarga de familias. Ahora las descargas pueden reanudarse tras una interrupción y cambiar de servidor si hay problemas de conexión.
- Hemos reducido el tiempo total necesario para insertar una familia por primera vez y la demora tras cancelar la operación.
- Hemos agilizado la actualización de la lista de sets y el cambio a un idioma ya descargado.
- Hemos acelerado la búsqueda. Ahora no distingue entre mayúsculas y minúsculas y trata «е» y «ё» como la misma letra.

### Interfaz y facilidad de uso

- Ahora puedes desplegar un set para ver sus familias directamente en la lista.
- Hemos añadido el progreso de la descarga y una estimación del tiempo restante.
- Hemos hecho más claro el cambio entre las pestañas **Sets** y **Families**.
- El campo de búsqueda se vacía al cambiar de pestaña.
