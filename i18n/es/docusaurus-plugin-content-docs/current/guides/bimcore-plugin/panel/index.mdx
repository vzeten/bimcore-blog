## Busca un set o una familia

1. En el campo **Search** de la ventana del plugin, escribe el nombre del set o de la familia.

## Abre la ficha del set

1. En la ventana del plugin, haz clic en el icono **i** a la derecha del set.
2. Se abrirá la ventana **Set Information** con las instrucciones, el chat, los proyectos, las familias y el historial de versiones del set.

![Ventana Set Information de un set](./img-11.png)

## Selecciona el idioma del contenido

1. En la pestaña **Complementos** de Revit, haz clic en **Settings**.
2. Se abrirá la ventana **User settings**.
3. En el campo **Content language** de esa ventana, selecciona **Русский** o **English**.

![Campo Content language en la ventana User settings](./img-09.png)

Si tienes algún problema, escríbenos a `mail@bimcore.one`.
