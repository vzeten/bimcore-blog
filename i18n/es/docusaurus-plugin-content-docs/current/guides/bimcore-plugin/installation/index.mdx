## 1. Cierra Revit

1. Guarda los proyectos abiertos en Revit.
2. Cierra Revit.

## 2. Descarga el instalador

1. Haz clic en [Descargar el instalador del plugin BIMCORE](https://revitcontentstorage.blob.core.windows.net/0-plugin-installers/bimcore.msi?sv=2023-01-03&st=2024-09-16T16%3A53%3A23Z&se=9999-09-17T16%3A53%3A00Z&sr=b&sp=r&sig=oVopKFMhyna0ItUuDXP4UNoV%2FNRg8KyIN9uv4z7Zk0M%3D).
2. El archivo bimcore.msi aparecerá en la lista de descargas del navegador.

## 3. Instala el plugin

1. Abre bimcore.msi desde la lista de descargas del navegador.
2. Si aparece el aviso "Windows protegió su PC", haz clic en **Más información**.
3. En ese mismo aviso, haz clic en **Ejecutar de todas formas**.
4. Si el instalador muestra una ventana con el texto "Autodesk Revit", cierra cualquier ventana de Revit que siga abierta.
5. Si apareció esa ventana del instalador, haz clic en **OK** para continuar.
6. Espera a que se cierre la ventana de instalación.

## 4. Abre el plugin en Revit

1. Inicia Revit.
2. Si aparece el cuadro de diálogo **Seguridad - Complemento sin firmar**, haz clic en **Cargar siempre**.
3. En Revit, abre la pestaña **Complementos**.
4. En **Complementos**, haz clic en **Panel**.

![Pestaña Add-Ins y botón Panel](./img-06.png)

5. Se abrirá la ventana del plugin con la interfaz en inglés.

Si tienes algún problema, escríbenos a `mail@bimcore.one`.

Continúa con [Registro e inicio de sesión](/guides/bimcore-plugin/sign-in).
