En el panel del plugin BIMCORE verás los sets de familias de INT LINES que has comprado. Cada set tiene un botón **Open** para abrir el proyecto del set. Cada familia de la lista tiene un botón **Insert** para colocarla en tu propio proyecto de Revit.

Las familias gratuitas están en un set independiente llamado **Free families**.

## Empieza a usar el plugin

1. [Instala el plugin BIMCORE y ábrelo en Revit](/guides/bimcore-plugin/installation).
2. [Regístrate e inicia sesión en el plugin BIMCORE](/guides/bimcore-plugin/sign-in) con la contraseña que recibirás por correo.
3. [Abre el proyecto de un set e inserta una familia](/guides/bimcore-plugin/sets).
4. [Busca una familia, consulta la información de un set y elige el idioma](/guides/bimcore-plugin/panel).

Si no aparecen tus sets en el panel, necesitas actualizar el plugin o has olvidado la contraseña, consulta las [preguntas frecuentes sobre el plugin BIMCORE](/guides/bimcore-plugin/faq).

Puedes consultar los cambios del plugin en [Novedades](/guides/bimcore-plugin/whats-new).
