После входа в панели плагина появятся наборы INT LINES, которые вы приобрели. Если их нет, войдите с почтой из заказа.

Бесплатные семейства лежат в отдельном наборе **Бесплатные семейства**.

Под названием каждого набора есть кнопка **Открыть** и надпись с числом семейств (например, **12 семейств**). Кнопка **Открыть** открывает проект набора, а нажатие на надпись с числом семейств раскрывает список семейств. У каждого семейства есть кнопка **Разместить**, чтобы вставить его в свой проект.

## Чтобы открыть проект набора

В панели плагина нажмите **Открыть** под нужным набором.

{/* СНИМОК ЗАМЕНИТЬ: панель с русскими наборами, язык контента «Русский»; рамки на «Открыть» и значок i. */}
![Список наборов в плагине](./img-07.png)

## Чтобы вставить семейство в свой проект

1. Откройте в Revit свой проект и нужный вид.
2. В панели плагина нажмите надпись с числом семейств под нужным набором.

{/* СНИМОК ЗАМЕНИТЬ: раскрытый русский набор; рамки вокруг числа семейств и кнопки «Разместить». */}
![Семейства раскрытого набора](./img-08.png)

3. У нужного семейства нажмите **Разместить**.
4. Щёлкните в нужном месте вида.
5. Чтобы закончить размещение, дважды нажмите **Esc**.

Если что-то не получилось, напишите нам в Telegram [https://t.me/IntLinesSupportBot](https://t.me/IntLinesSupportBot).
