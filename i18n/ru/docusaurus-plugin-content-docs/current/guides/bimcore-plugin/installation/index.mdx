Плагин BIMCORE работает в Revit 2019–2027. После установки на вкладке **Надстройки** вы увидите кнопку **Панель**, которая открывает панель плагина.

## Чтобы скачать установщик

1. Сохраните открытые проекты и закройте Revit.
2. Нажмите [Скачать установщик плагина BIMCORE](https://revitcontentstorage.blob.core.windows.net/0-plugin-installers/bimcore.msi?sv=2023-01-03&st=2024-09-16T16%3A53%3A23Z&se=9999-09-17T16%3A53%3A00Z&sr=b&sp=r&sig=oVopKFMhyna0ItUuDXP4UNoV%2FNRg8KyIN9uv4z7Zk0M%3D) и дождитесь скачивания файла bimcore.msi.

![Файл bimcore.msi в загрузках браузера](./img-01.png)

## Чтобы установить плагин
1. Откройте скачанный файл bimcore.msi.
2. Если появилось окно **Система Windows защитила ваш компьютер**, нажмите **Подробнее**, затем **Выполнить в любом случае**.

![Ссылка Подробнее](./img-02.png)

![Кнопка Выполнить в любом случае](./img-03.png)

3. Если установщик просит закрыть Revit, закройте его и нажмите **OK**.

![Окно со строкой Autodesk Revit и кнопкой OK](./img-04.png)

4. Дождитесь, пока окно установки закроется.

![Окно Please wait while Windows configures bimcore](./img-05.png)

## Чтобы открыть плагин в Revit

1. Запустите Revit.
2. Если при первом запуске появилось окно **Надстройка без подписи**, нажмите **Всегда загружать**.

![Кнопка Всегда загружать](./img-10.png)

3. На вкладке **Надстройки** нажмите **Панель**.

![Вкладка Надстройки и кнопка Панель](./img-06.png)

Если что-то не получилось, напишите нам в Telegram [https://t.me/IntLinesSupportBot](https://t.me/IntLinesSupportBot).
