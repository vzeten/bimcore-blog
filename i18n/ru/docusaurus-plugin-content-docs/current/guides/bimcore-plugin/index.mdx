В панели плагина BIMCORE вы увидите приобретённые наборы семейств INT LINES. У каждого набора есть кнопка **Открыть**, которая открывает проект набора. У семейств в списке набора есть кнопка **Разместить**, чтобы вставить семейство в свой проект Revit.

Бесплатные семейства лежат в отдельном наборе **Бесплатные семейства**.

## Чтобы начать пользоваться плагином

1. [Как установить плагин BIMCORE и открыть его в Revit](/guides/bimcore-plugin/installation).
2. [Как зарегистрироваться и войти в плагин BIMCORE](/guides/bimcore-plugin/sign-in), используя пароль из письма.
3. [Как открыть проект набора и вставить семейство](/guides/bimcore-plugin/sets).
4. [Как найти семейство, открыть информацию о наборе и выбрать язык](/guides/bimcore-plugin/panel).

Если наборы не появились в панели, нужно обновить плагин или восстановить пароль, откройте [Ответы на вопросы о плагине BIMCORE](/guides/bimcore-plugin/faq).

Об изменениях в плагине читайте в разделе [Что нового](/guides/bimcore-plugin/whats-new).
