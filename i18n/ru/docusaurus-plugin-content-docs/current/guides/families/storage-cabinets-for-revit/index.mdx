## 1. ОБЩИЕ ДАННЫЕ

-   Название набора: Семейства Шкафы
-   Версия набора 1.0.0
-   Версия Revit: 2019

### Описание

Этот набор семейств для Revit предназначен для моделирования шкафов в Autodesk Revit.

С помощью семейств можно создать шкафы, фасады, витрины, карнизы по точным размерам.

Подходит дизайнерам интерьера и архитекторам. Для моделирования шкафов мебельщиками семейства недостаточно детализированные.

### Загрузка и размещение

Для того чтобы посмотреть и загрузить нужные семейства из набора, можно открыть Проект шкафов и скопировать семейства при помощи комбинации клавиш Ctrl+C, а затем вставить в свой проект Ctrl+V. Или открыть папку с файлами семейств и перетащить мышкой в проект.

## 3. CЕМЕЙСТВА

### Шкаф

Семейство Шкаф используется для построения шкафов с ящиками или антресолью.

![Шкафы для Revit — Шкаф](./img-02.png)

Здесь можно включить/выключить следующие элементы:

-   Антресоль
-   Ящики
-   Цоколь
-   Открывание
-   Фасады антресоль
-   Фасады шкаф
-   Фасады ящики
-   УГО_Вешалки (на плане сверху)
-   УГО_Х (на плане сверху)

#### Размеры

![Шкафы для Revit — Размеры](./img-03.png)

Шкаф высота - это параметр высоты, в котором есть другие мелкие высоты элементов, если они включены по галочке (Цоколь высота, Ящики высота, Шкаф-фасад высота, Антресоль высота).

Есть параметры серого цвета, которыми нельзя управлять. Но они нужны для понимания расчётов размеров. Например, *Фасад ширина*. Параметр показывает ширину фасадов, т.к.она считается по формуле исходя из количества фасадов и ширины самого шкафа.

Если фасады выключены, корпус сдвигается на толщину фасадов.

#### Количество фасадов

![Шкафы для Revit — Количество фасадов](./img-04.png)

Количество фасадов может быть от 1 до 4.

Номера фасадов идут по порядку слева направо, где Ф1 это крайний левый, а Ф4 - крайний правый. Ширина фасадов не задаётся, а считается автоматически.

#### Открывание

![Шкафы для Revit — Открывание](./img-05.png)

Основными типами открывания в данном семействе являются Левое открывание и Правое. Если выключить Левое открывание (Ф_Левое), то автоматически включится Правое для всех видимых фасадов по вертикали.

Когда для антресоли или ящика нужно показать другой тип открывания, то включаем дополнительные галочки. Это *Антресоль вверх, Ящики вниз и Ящики выдвижные*. Для фасада же основного (Фасад-шкаф) остаётся левое или правое открывание.

#### Опции

![Шкафы для Revit — Опции](./img-06.png)

Фасады могут быть стандартными( простыми, без фрезеровки) и рамочными.

Количество ящиков по высоте может быть от 1 и более, но нужно следить за корректностью по размерам, чтобы не появилась ошибка.

*Ящики на всю ширину* - этот параметр убирает деление по фасадам и вытягивает ящики на всю ширину шкафа.

При зеркальном отображении открывания тоже зеркалятся, поэтому названия будут противоположными: Левое станет Правым и наоборот.

Количество ящиков по высоте может быть от 1 и более, но нужно следить за корректностью по размерам, чтобы не появилась ошибка.

#### Фасад

Фасад - это стандартные и самые популярные типы фасадов.

![Шкафы для Revit — Фасад](./img-41.jpg)

Фасад стандарт - простой прямоугольный фасад.

Фасад рамка снаружи - рамочный прямоугольный фасад, подходит для неоклассики.

Фасад рамка внутри - рамка находится внутри, за стеклом.

![Шкафы для Revit — Фасад](./img-42.jpg)

Ручки из Общего раздела дополнены в данном семействе Интегрированной и Вырезом. И получается:

-   Кнопка
-   Скоба
-   Т-образная
-   Ракушка
-   Кожаная петля
-   Кожаная скоба
-   Накладная
-   Интегрированная
-   Вырез

Для Скобы, Вырез, Накладной и Т-образной ручки работает параметр Ручка длина.

#### Фасад волна

Фасад волна - фасад с фрезеровкой, похожей по форме на волну.

![Шкафы для Revit — Фасад волна](./img-43.jpg)

Ширина паза и гребня регулируется, только у гребня будет примерная ширина. Это получается из-за специфической работы массива в Revit.

#### Фасад рейки-квадрат

Фасад рейки-квадрат  - фасад с фрезеровкой, похожей по форме на рейки.

![Шкафы для Revit — Фасад рейки-квадрат](./img-44.jpg)

Ширина паза и гребня регулируется, только у гребня будет примерная ширина. Это получается из-за специфической работы массива в Revit.

В отличие от других семейств с фрезеровкой, здесь регулируется глубина паза.

#### Фасад рейки-полукруг

Фасад рейки-полукруг - фасад с фрезеровкой, похожей по форме на полукруглые рейки.

![Шкафы для Revit — Фасад рейки-полукруг](./img-45.jpg)

Ширина паза и гребня регулируется, только у паза будет примерная ширина. Это получается из-за специфической работы массива в Revit.

#### Фасад стеклянный

Фасад стеклянный - фасад со стеклом, шпросами и шпросами в виде креста.

Шпросы - это разделительные планки на фасаде.

![Шкафы для Revit — Фасад стеклянный](./img-46.jpg)

#### Фасад классика

Фасад классика - рамочные фасады со сложной фрезеровкой. Профиль можно менять внутри семейства, но при большой ширине профиля могут быть ошибки в работе.

![Шкафы для Revit — Фасад классика](./img-47.jpg)

![Шкафы для Revit — Фасад классика](./img-48.jpg)

Когда **Фасад высота** меньше 150 мм, все типы фасада становятся Типом 1. А ширина рамки фасада сверху и снизу меньше в 2 раза, в отличие от боковых рамок.

Когда **Фасад высота** меньше 100 мм, все типы фасада становятся простым прямоугольным фасадом без фрезеровок.

Фасад по ширине меньше 150мм быть не может.

#### Фасад жалюзи

Фасад жалюзи - фасад с вертикальными или горизонтальными ламелями.

![Шкафы для Revit — Фасад жалюзи](./img-49.jpg)
