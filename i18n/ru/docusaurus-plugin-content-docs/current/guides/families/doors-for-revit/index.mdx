## 1. ОБЩИЕ ДАННЫЕ

#### Название набора: Семейства Двери

#### Версия набора 1.2.0

#### Версия Revit: 2019

### Описание

Этот набор семейств для Revit предназначен для моделирования дверей и проёмов в Autodesk Revit.

С помощью семейств можно создать двери входные и межкомнатные одностворчатые, полуторные, двустворчатые, двери складные, раздвижные, поворотные, проёмы с обрамлением и без, двери с фрамугами.

Подходит дизайнерам интерьера и архитекторам. Геометрия коробки, полотна и других элементов сделаны упрощённо, чтобы не утяжелять и так сложные семейства.

### Загрузка и размещение

Для того чтобы посмотреть и загрузить нужные семейства из набора, можно открыть папку с файлами семейств и перетащить мышкой в проект.

<u>ВАЖНО!</u> Размещать двери нужно только на плане сверху, не в 3д (иначе может выскакивать ошибка и Revit не даст разместить дверь).

## 3. ОБЩИЕ ЭЛЕМЕНТЫ

Общие элементы - элементы, которые часто повторяются в семействах.

### Открывание

Параметры открывания дверей находятся в параметрах типа.

![Двери для Revit — Открывание](./img-03.jpg)\
Типы открывания:

- Левое открывание

- Правое открывание

- Наружу

- Внутрь

![Двери для Revit — Открывание](./img-04.jpg)

Для двустворчатых дверей, где нет Левого или Правого открывания (с одинаковыми полотнами), нужно выбирать только Наружу или Внутрь.

![Двери для Revit — Открывание](./img-05.jpg)

Угол открывания работает для 3D полотен и 2D полотен отдельно, т.к.отображение на 2D сделано условными линиями.

![Двери для Revit — Открывание](./img-06.jpg)

В сдвижных одностворчатых дверях есть Левое и Правое открывание.

Наружу и Внутрь - нет. Для этого используем элементы управления - стрелки отзеркаливания. В двустворчатых сдвижных - только стрелки.

Также данные стрелки показывают наружную сторону семейств. То есть по ним можно понимать, где будут Отделка снаружи, а где Отделка внутри и т.д.

![Двери для Revit — Открывание](./img-07.jpg)

Для удобства обозначения открывания дверей в спецификациях, был создан общий параметр *INT_Открывание двери.* Находится он в разделе Идентификация.

Если параметр серый (неактивный), значит внутри него прописана специальная формула и из-за этого параметром нельзя управлять.

Если параметр чёрного цвета (активный), значит заполнять информацию можно самостоятельно под конкретную комплектацию дверей. Это применимо практически ко всем сдвижным дверям.

Для *двустворчатых* дверей, где нет Левого или Правого открывания, будет прописываться лишь значение Наружу или Внутрь.

![Двери для Revit — Открывание](./img-08.jpg)

На Высоком уровне детализации - отображается всё как и в 3D, кроме полотна с ручками. Это 2D полотно поворачивается отдельно от полотна в 3D.

Средний уровень детализации - геометрия коробки отрисована линиями, упрощённо. Наличники и доборы скрыты. Полотно отображается просто в виде линии.

![Двери для Revit — Открывание](./img-09.jpeg)

### Типоразмеры

![Двери для Revit — Типоразмеры](./img-10.jpg)

Типоразмеры у всех семейств начинаются с Размера проёма (Ширина проёма и Высота проёма).

У межкомнатных и сдвижных дверей далее идёт Ширина полотна (или несколько полотен 600+600 и т.д.)

Тип полотна: Глухое или Стекло

Открывание: П Л НАР ВН

Остекление ОС - размещение: Слева, Справа, Сверху, Слева и Справа, Слева и Сверху, Справа и Сверху, Слева Справа и Сверху.

### Фурнитура (Ручки, замки..)

Ручки

![Двери для Revit — Фурнитура (Ручки, замки..)](./img-11.jpg)

Типы ручек можно выбрать в выпадающем списке, если это не раздвижные двери (тогда по умолчанию только раздвижные ручки). Это:

- Нет

- Квадрат

- Круг

- На планке

- Штанга

- Раздвижная

- Шар

- Скоба

Для обозначения в спецификации всей фурнитуры был создан общий параметр *INT_Фурнитура двери.* Находится он в разделе Идентификация.\
Заполнять информацию нужно самостоятельно под конкретную комплектацию дверей.

![Двери для Revit — Фурнитура (Ручки, замки..)](./img-12.jpg)

Ручку на 2D можно выключить (например, если у двери тип ручки Раздвижная).

![Двери для Revit — Фурнитура (Ручки, замки..)](./img-13.png)

Параметр *Ручка штанга только снаружи* включает ручку штангу только с одной стороны, а с другой стороны можно выбрать любую другую ручку.

![Двери для Revit — Фурнитура (Ручки, замки..)](./img-14.png)

Типы замков:

- Верхний замок (у входных дверей)

- Нижний замок (есть во всех семействах дверей, а у входных - всегда включен)

У Нижнего замка есть дополнительные опции размещения внутри или снаружи Завёртки и Ключа:

- Ключ-Завёртка

- Завёртка-Ключ

- Ключ-Ключ

![Двери для Revit — Фурнитура (Ручки, замки..)](./img-15.png)

Размеры всей фурнитуры не изменяются. Можно менять только смещение от края двери до центральной оси ручек, за это отвечает параметр *Ручка сдвиг сбоку.*

*Ручка штанга* размещается немного дальше от стандартного размещения всех ручек и замков.

*Глазок* для входных дверей размещается по центру, если не включено Зеркало с внутренней стороны полотна. Тогда Глазок сдвигается к оси ручек.\
\
Высота размещения ручек 1000мм от низа полотна.

### Отделка

Если в проекте отделка сделана дополнительными тонкими стенами, которые присоединяются к основной стене, необходимо чтобы дверь сдвигалась на эту толщину отделки и попадала в размеры.

![Двери для Revit — Отделка](./img-16.jpeg)

Отделка может быть как снаружи, так и внутри стены. Чтобы убрать смещение под отделку, нужно поставить значение 0 в параметры Отделка толщина.

### Откосы

![Двери для Revit — Откосы](./img-17.jpg)

Откосы выполнены во всех семействах дверей общими вложенными семействами *INT 19 Откосы дверей снаружи* и *INT 19 Откосы дверей внутри*. Они находятся в группе Стены. Их можно включить либо выключить нажав на параметры Откосы снаружи и Откосы внутри.

![Двери для Revit — Откосы](./img-18.jpg)

Чтобы площадь откосов считалась по одной грани, а не по всему объёму (что будет давать некорректные данные в спецификацию), сделана разбивка по материалам.

*Материал откосов не для спецификации* - это материал заполнения откоса. Он не нужен для спецификации.

А *материал откосов* - это внешняя грань откоса, к которой применён материал инструментом краска. Материал можно использовать для подсчёта площади.

### Размеры

Ширина и Высота - это размеры проёма.

Примерная ширина и Примерная высота, Толщина - это размеры полотна.

#### Четверть

![Двери для Revit — Четверть](./img-19.jpg)

Четверть - это вырез в проёме для коробки. По умолчанию значение равно 0.

#### Глубина вставки

![Двери для Revit — Глубина вставки](./img-20.jpg)

Глубина вставки - глубина смещения полотна с коробкой внутрь проёма. По умолчанию значение равно 0.

#### Наличники и доборы

![Двери для Revit — Наличники и доборы](./img-21.jpg)

Наличники зафиксированы к грани добора и смещаются вместе с ним. Даже если доборы выключены, а нужно переместить наличники, то просто измените толщину доборов.

#### Фальш-фрамуга

![Двери для Revit — Фальш-фрамуга](./img-22.jpg)

Фальш-фрамугу в данном семействе можно включить проставив значение больше 0 у параметров *Фальш-фрамуга снаружи высота и Фальш-фрамуга внутри высота* . Тогда к значению Наличники ширина добавится одно из этих значений и наличник увеличится вверх.

Если наличники выключены, то фальш-фрамуга не работает.

Остекление (или фрамуги) используется в семействах:

- Дверь входная одностворчатая с остеклением

- Дверь входная двустворчатая с остеклением

- Дверь межкомнатная одностворчатая с остеклением

- Дверь межкомнатная двустворчатая с остеклением

![Двери для Revit — Остекление (Фрамуги)](./img-23.jpg)

Остекление может размещаться:

- Сверху

- Справа

- Слева

- Справа и Слева

- Справа и Сверху

- Слева и Сверху

- Слева, Справа и Сверху

Параметр *Боковое остекление до верха* - сдвигает вверх боковые фрамуги.

![Двери для Revit — Остекление (Фрамуги)](./img-24.jpg)

![Двери для Revit — Остекление (Фрамуги)](./img-25.jpg)

![Двери для Revit — Остекление (Фрамуги)](./img-26.jpg)

Шпросы - это элементы полотна.

А дополнительные шпросы (Шпрос 1 сверху, 2 и 3 сверху, 4 и 5 сверху, Шпросы боковые) - это шпросы, которые включаются у остекления.

## 4. СЕМЕЙСТВА

### Двери межкомнатные

Семейства межкомнатных дверей - это двери, соединяющие комнаты внутри помещения. Полотно открывается стандартно.

Межкомнатные двери делятся на:

- Одностворчатые (одинарные/с одним полотном)

- Двустворчатые (двойные/полуторные/с двумя полотнами)

- С остеклением (фрамугами)

- Скрытого монтажа

![Двери для Revit — Двери межкомнатные](./img-27.png)

Здесь можно включить/выключить следующие элементы:

- Нижний замок

- Невидимые линии 2D

- Ось 2D

- Шпросы

- Порог

- Наличники внутри

- Доборы снаружи

- Доборы внутри

- Откосы снаружи

- Откосы внутри

- Филёнки количество (от 0 до 3)

- Рамка классика

- Штапик

- Наличник компланарный

![Двери для Revit — Двери межкомнатные](./img-28.jpg)

Данные типы полотен подходят ко всем межкомнатным(кроме двери скрытого монтажа) и сдвижным дверям.

Благодаря доп.опциям полотна можно сделать как простое полотно без фрезеровки, так и классические полотна глухие и со стеклом.

![Двери для Revit — Двери межкомнатные](./img-29.jpg)

Количество филёнок может быть от 0 до 3. При значении =0, будет простое полотно без вырезов.

![Двери для Revit — Двери межкомнатные](./img-30.png)

![Двери для Revit — Двери межкомнатные](./img-31.jpg)

Параметр Наличник компланарный сдвигает полотно с коробкой к краю наличника, чтобы они были в одну плоскость.

Если этот параметр включен, то нельзя изменять Глубину вставки, она не работает.

#### Размеры

![Двери для Revit — Размеры](./img-32.png)

У полотна размеры немного меньше, чем в параметре Примерная ширина и Примерная высота из-за зазоров по периметру полотна.

*Примерная ширина* = Ширина-Коробка ширина\*2

*Примерная высота* = Высота-Коробка сверху высота-10(или - Порог высота)

Если порог выключен, то снизу полотна есть зазор около 10мм.

![Двери для Revit — Размеры](./img-33.png)

В двустворчатых семействах есть как двустворчатые двери, так и полуторные. Просто нужно выбрать нужный типоразмер.

Размеры светового проёма:

Примерная ширина = 1_Полотно ширина + 2_Полотно ширина

Примерная высота = Полотно высота

![Двери для Revit — Размеры](./img-34.png)

Дверь скрытого монтажа тоже может открываться Наружу и Внутрь.

![Двери для Revit — Размеры](./img-35.png)

Параметр Скрытый плинтус высота сдвигает вверх Отделку внутри, что позволяет разместить скрытый плинтус.

Параметр До потолка убирает коробку сверху, над полотном, и часть отделки сверху.

Также в набор добавлена Дверь скрытого монтажа двустворчатая.

![Двери для Revit — Размеры](./img-36.png)

Параметр Многослойная стена в дверях скрытого монтажа нужно включать, когда у вас отделка стен сделана дополнительными слоями внутри основной стены, а не отдельными тонкими стенами.

![Двери для Revit — Размеры](./img-37.png)

Подрезка под теневой профиль настраивается в Размерах, если стоит значение для высоты 0 мм, то дверь выглядит как обычно. А если поставить 20 мм, то появляется подрезка под профиль.

#### Материалы

![Двери для Revit — Материалы](./img-38.png)

Материалы филёнок находятся в типе.

Материал *полотна классика* подходит для дверей с филёнками (вырезами), а материалы простого полотна - когда филёнки = 0.

### Двери сдвижные

Семейства сдвижных дверей - это двери, в которых полотна сдвигаются/раздвигаются/смещаются/поворачиваются (в отличие от обычных межкомнатных). Сдвижные двери делятся на:

- Пенал — одностворчатая, двустворчатая

- Книжка — одностворчатая, двустворчатая

- Compack — одностворчатая, двустворчатая

- Роторная — одностворчатая, двустворчатая

- Pivot — одностворчатая, двустворчатая

- Купе — одностворчатая, двустворчатая

- Magic — одностворчатая, двустворчатая

- Раздвижная 2 полотна

- Раздвижная 3 полотна

- Раздвижная 4 полотна

Геометрия элементов сдвижных дверей такая же, как у межкомнатных. Это коробка, наличники, доборы и т.д. Различия есть в размерах и доп.элементах.

#### Размеры

В семействах Дверей входных и технических, в отличие от других семейств, есть параметры Дверной блок и Монтажный зазор.

![Двери для Revit — Размеры](./img-55.png)

Дверной блок ширина = Ширина - Монтажный зазор\*2

Дверной блок высота = Высота - Монтажный зазор - Монтажный зазор снизу

Примерная ширина и Примерная высота по факту немного меньше значений в параметрах, т.к. есть зазоры несколько мм по периметру. (То есть, если Примерная ширина в таблице = 880мм, то в реальности 874мм.

Поэтому лучше размеры привязывать не к линиям полотна, а к опорным плоскостям)

При увеличении Толщины полотна увеличивается и глубина коробки.

![Двери для Revit — Размеры](./img-56.png)

В двустворчатых семействах есть как двустворчатые двери, так и полуторные. Просто нужно выбрать нужный типоразмер 1.5х или 2х.

Дверной блок ширина = Ширина - Монтажный зазор\*2

Дверной блок высота = Высота - Монтажный зазор - Монтажный зазор снизу

Световой проём ширина = Примерная ширина = 1_Полотно ширина + 2_Полотно ширина.

Световой проём высота = Примерная высота = Полотно высота
