## 1. ОБЩИЕ ДАННЫЕ

-   Название набора: Семейства Кухня
-   Версия набора 3.2.1
-   Версия Revit: 2019

### Описание

Этот набор семейств для Revit предназначен для моделирования кухни в Autodesk Revit.

С помощью семейства можно создать кухню по точным размерам и посчитать количество модулей кухни.

Подходит дизайнерам интерьера и архитекторам. Для моделирования кухни мебельщиками семейства недостаточно детализированные.

### Загрузка и размещение

Для того чтобы посмотреть и загрузить нужные семейства из набора, можно открыть Проект с кухней и скопировать семейства при помощи комбинации клавиш Ctrl+C, а затем вставить в свой проект Ctrl+V. Или открыть папку с файлами семейств и перетащить мышкой в проект.

## 3. ОБЩИЕ ЭЛЕМЕНТЫ

В этом разделе вы узнаете из каких элементов состоят модули и как их настраивать.

### Общие элементы

Общие элементы - элементы, которые повторяются в каждом кухонном модуле.

![Кухни для Revit — Общие элементы](./img-02.jpg)

Общими элементами всех кухонных модулей являются:

-   Фасады
-   Ручки
-   Ножки
-   Открывание
-   Корпус
-   Задняя стенка (часть корпуса)
-   Левый торец (часть корпуса)
-   Правый торец (часть корпуса)

### Фасады

![Кухни для Revit — Фасады](./img-03.jpg)

Типы фасадов можно выбрать в выпадающем списке у каждого семейства модуля. Это:

-   Нет фасада
-   Стандарт
-   Рамка внутри
-   Рамка снаружи
-   С интегрированной ручкой сверху
-   С интегрированной ручкой слева
-   С интегрированной ручкой справа
-   С интегрированной ручкой снизу

![Кухни для Revit — Фасады](./img-04.jpg)

### Ручки

#### Типы ручек

![Кухни для Revit — Типы ручек](./img-05.png)

Типы ручек можно выбрать в выпадающем списке у каждого семейства модуля. Это:

-   Нет ручек
-   Скоба
-   Накладная
-   Кнопка
-   Т-образная

Для накладной ручки нужно поставить значение параметра РУ.Сдвиг =2мм, чтобы она сдвинулась на край фасада.

![Кухни для Revit — Типы ручек](./img-06.png)

У Т-образной ручки меняется отображение при разной длине ручки (РУ.Длина).

#### Размещение ручек

![Кухни для Revit — Размещение ручек](./img-07.png)

Размещение ручек сделано цифрами от 1 до 9. Визуально это похоже на размещение цифр на клавиатуре.

Ещё можно посмотреть подсказку в самом параметре РУ.Размещение.

Положение ручек может быть горизонтальным и вертикальным. За это отвечает параметр РУ.Горизонтально.

### Открывание

#### Типы открывания

![Кухни для Revit — Типы открывания](./img-08.png)

Типы открывания можно выбрать в выпадающем списке у каждого семейства модуля. Это:

-   Нет открывания
-   Левое
-   Правое
-   Вниз
-   Вверх
-   Ящик
-   Двойное
-   Левый сдвиг
-   Правый сдвиг
-   Двойной сдвиг
-   Подъемное
-   Подъемное наклонное
-   Складное
-   2 ящика

Открывание фасадов не зависит от положения ручек.

#### Разные виды открывания RU / ENG

![Кухни для Revit — Разные виды открывания RU / ENG](./img-09.png)

Чтобы включить Открывание RU или ENG, необходимо зайти в Видимость вида, далее в Мебель и там выбрать нужный вам вид открывания.

### Торцы

![Кухни для Revit — Торцы](./img-10.png)

Торцы слева (Л) и справа (П) есть во всех корпусах модулей и их можно выключить, если нужно. Но по умолчанию они включены.

Л.Торец, П.Торец -  добавляют дополнительную панель сбоку и закрывают торец фасада.

![Кухни для Revit — Торцы](./img-11.png)

В модулях, которые устанавливаются на пол, добавляются дополнительные параметры к торцам. Это: Л.До пола,П.До пола (что позволяет опустить торцы до пола) и Л.Торец, П.Торец.

### Нижний модуль

Нижний модуль используется для построения шкафов кухни, которые размещаются на полу и являются рабочей поверхностью при готовке.

![Кухни для Revit — Нижний модуль](./img-12.png)

Здесь можно включить/выключить следующие элементы:

-   Столешница
-   Ручки
-   Фасады
-   Корпус
-   Задняя стенка
-   Полка
-   Скрытый ящик (отображается штриховой линией)
-   Ножки
-   ручки Gola
-   разные опции Торцов, про которые говорилось ранее

![Кухни для Revit — Нижний модуль](./img-13.png)

Также есть Оборудование:

-   Электрическая плита
-   Раковина (с ней автоматически включается Смеситель)
-   Оборудование в фасаде

#### Типоразмеры

![Кухни для Revit — Типоразмеры](./img-14.png)

Типоразмеры названы по количеству фасадов в модуле:

-   х1
-   х2
-   х3
-   х4

Номера фасадов идут по порядку снизу вверх, где Ф1 это нижний фасад, а Ф4 - верхний фасад.

Чтобы изменять количество фасадов в нижнем модуле, нужно выбирать соответствующие типоразмеры,а не параметры-экземпляры.

Если один фасад, то выбираем х1. Если два фасада - х2. И так до четырёх фасадов, это максимальное значение в данном семействе.

#### Размеры

![Кухни для Revit — Размеры](./img-15.png)

![Кухни для Revit — Размеры](./img-16.png)

Ширина, Глубина, Высота модуля - это габариты именно корпуса. Фасады толщина, Столешница толщина, Цоколь высота - отдельные параметры.

Глубина столешницы на виде сверху имеет фиксированное значение и  состоит из размеров: Глубина+Фасады толщина+5мм.

Есть параметры серого цвета, которыми нельзя управлять. Но они нужны для понимания расчётов размеров. Например, Столешница высота. Параметр складывает все высоты и показывает важную крайнюю точку рабочей плоскости, когда включена Столешница. (см. картинки)

Т.к. в семействе есть 4 типоразмера, а это значит есть 4 фасада, можно менять конкретно для каждого отдельные параметры.

Если выбран типоразмер х1, то меняем все параметры с цифрой 1: Ф1.Высота(в х1 равно высоте корпуса), ОБ1.Тип, ОБ1.Закрыто фасадом, Ф1.Тип, Ф1.Открывание, РУ1.Размещение. Если выбран типоразмер х2, то меняем все параметры с цифрой 1 и 2.

![Кухни для Revit — Размеры](./img-17.png)

Начинать построение Ф.Высоты лучше с нижнего, первого фасада. Т.к. Ф.Высота последнего,верхнего фасада не работает.

Например, выбран типоразмер х3, Ф1.Высота и Ф2.Высота будут изменяемы, а Ф3.Высота рассчитывается исходя из двух первых высот.

Если Ф.Высоты будут больше Высоты корпуса, то будет ошибка. Если такое произошло, просто вернитесь действием назад и проставьте небольшие значения в Ф.Высота.

#### Электрическая плита

![Кухни для Revit — Электрическая плита](./img-18.png)

Электрическая плита бывает нескольких типов, которые выбираем в выпадающем списке. Это:

-   450 (3 конфорки)
-   580 (4 конфорки)
-   880 (6 конфорок)

Обязательно выбираем с начальным заголовком INT 02 Электр.плита. Т.к. в выпадающие списки подгружаются различные другие семейства и их выбирать не нужно.

#### Раковина

![Кухни для Revit — Раковина](./img-19.png)

Раковина бывает двух типов, которые выбираем в выпадающем списке. Это:

-   Настольная
-   Подстольная

Обязательно выбираем с начальным заголовком INT 02 Раковина. Т.к. в выпадающие списки подгружаются различные другие семейства и их выбирать не нужно.

Смеситель кухонный к раковине:

-   высотой 360
-   высотой 450

Обязательно выбираем с начальным заголовком INT 02 Смеситель кухонный.

![Кухни для Revit — Раковина](./img-20.png)

Раковину и Электрическую плиту на столешнице можно сдвигать влево или вправо от центральной оси. Также есть параметр для раковины Раковина ширина.

Если конфигурация данных элементов вам не подходит, выключите их и разместите в проекте отдельное семейство.

#### Ручки Gola

![Кухни для Revit — Ручки Gola](./img-21.png)

Ручки Gola можно включить сверху корпуса, под столешницей - это Gola 1. А ручка Gola 2 будет между ящиками по центру корпуса. Высота корпуса может быть выше/ниже, но высота отдельных фасадов h в таком случае изменяется равномерно, Gola 2 всегда находится в центре.

Оборудование бывает нескольких типов:

-   Встроенное
-   Интегрированное

![Кухни для Revit — Оборудование](./img-22.png)

-   Микроволновка встроенная
-   Морозильник встроенный
-   Подогреватель посуды
-   Холодильник встроенный
-   Сушка для посуды

![Кухни для Revit — Оборудование](./img-23.png)

Интегрированное оборудование:

-   Винный шкаф интегрированный
-   Морозильник интегрированный
-   Посудомойка интегрированная

-   Холодильник интегрированный

#### Типоразмеры

![Кухни для Revit — Типоразмеры](./img-54.png)

Типоразмеры названы по количеству фасадов в модуле:

-   х1
-   х2
-   х3
-   х4
-   х5
-   х6

Номера фасадов идут по порядку снизу вверх, где Ф1 это нижний фасад, а Ф6 - верхний фасад.

Чтобы изменять количество фасадов в пенале, нужно выбирать соответствующие типоразмеры,а не параметры-экземпляры. Если один фасад, то выбираем х1. Если два фасада - х2. И так до шести фасадов, это максимальное значение в данном семействе.

#### Размеры

![Кухни для Revit — Размеры](./img-55.png)

Ширина, Глубина, Высота модуля - это габариты именно корпуса. Фасады толщина, Цоколь высота - отдельные параметры.

Т.к. в семействе есть 6 типоразмеров, а это значит есть 6 фасадов, можно менять конкретно для каждого отдельные параметры.

Если выбран типоразмер х1, то меняем все параметры с цифрой 1: Ф1.Высота(в х1 равно высоте корпуса), Ф1.Тип, Ф1.Открывание, РУ1.Размещение. Если выбран типоразмер х2, то меняем все параметры с цифрой 1 и 2.

![Кухни для Revit — Размеры](./img-56.png)

Начинать построение Ф.Высоты лучше с нижнего, первого фасада. Т.к. Ф.Высота последнего,верхнего фасада не работает. Например, выбран типоразмер х3, Ф1.Высота и Ф2.Высота будут изменяемы, а Ф3.Высота рассчитывается исходя из двух первых высот.

Если Ф.Высоты будут больше Высоты корпуса, то будет ошибка. Если такое произошло, просто вернитесь действием назад и проставьте небольшие значения в Ф.Высота.
