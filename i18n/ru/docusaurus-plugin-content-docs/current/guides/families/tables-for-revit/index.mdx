## 1. ОБЩИЕ ДАННЫЕ

- Название набора: Стеллажи

- Версия набора 1.2.0

- Версия Revit: 2019

#### Описание

Набор семейств столов для Revit предназначен для работы в Autodesk Revit и использования в BIM-проектах интерьеров и архитектуры. Библиотека включает параметрические семейства стеллажей и декора.

Набор предназначен для дизайнеров интерьера, архитекторов и проектировщиков, работающих в Autodesk Revit над жилыми и общественными пространствами.

#### Загрузка и размещение

Для того чтобы посмотреть и загрузить нужные семейства из набора, можно открыть **Проект со столами** и скопировать семейства при помощи комбинации клавиш Ctrl+C, а затем вставить в свой проект Ctrl+V. Или открыть папку с файлами семейств и перетащить мышкой в проект.

## 3. СЕМЕЙСТВА

### Столы

##### Общее. Размеры

![Столы для Revit — Общее. Размеры](./img-03.png)

У большей части параметрических столов есть следующие общие параметры, которые управляют габаритами:

INT_Ширина = Столы ширина

INT_Глубина = Столы глубина

INT_Высота = Столы высота

Также у столов можно изменять значения у параметров Ножки ширина, Ножки глубина, Столешница толщина и Царги высота.

![Столы для Revit — Общее. Размеры](./img-04.png)

##### УГО

На виде сверху можно включить условно-графическое обозначение (УГО) для раздвижной столешницы с помощью параметра “УГО”.

Ширину УГО можно поменять с помощью параметра УГО_Ширина столешницы.

##### Опции

![Столы для Revit — Опции](./img-06.png)

Здесь можно выбрать количество ножек:\
- 4 ножки

\- 2 ножки

\- 1 ножка

Для 4 ножек доступен выбор формы:

\- 4_Прямоугольник

\- 4_Прямоугольник под углом

\- 4_Прямоугольник 45°

\- 4_Прямоугольник 45° под углом

\- 4_Прямоугольник скошенный

\- 4_Конус

\- 4_Конус под углом

\- 4_Классика

Для 2 ножек доступен выбор формы:

\- 2_П-образные

\- 2_Т-образные

\- 2_Прямоугольник

Для 1 ножки доступен выбор формы:

\- 1_Прямоугольник

\- 1_Цилиндр
