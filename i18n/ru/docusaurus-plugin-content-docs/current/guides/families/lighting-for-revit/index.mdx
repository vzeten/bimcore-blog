## 1. ОБЩИЕ ДАННЫЕ

- Название набора: Светильники
- Версия набора 1.1.0
- Версия Revit: 2019

### Описание

![Светильники для Revit — витрина набора](./showroom.png)

Этот набор семейств предназначен для работы в Autodesk Revit и использования в BIM-проектах интерьеров и архитектуры.

Подходит дизайнерам интерьера, архитекторам. Геометрия светильников и других деталей сделана упрощенно инструментами программы Revit.

В семействах добавлены электрические коннекторы и файлы фотометрической сетки.

### Загрузка и размещение

Для того чтобы посмотреть и загрузить нужные семейства из набора, можно открыть Проекты с освещением и скопировать семейства при помощи комбинации клавиш Ctrl+C, а затем вставить в свой проект Ctrl+V.

Также можно открыть папку с файлами семейств и перетащить мышкой в проект.

Большинство светильников сделано на основе грани. Размещайте их на плане потолка или на 3д-виде.

## 3. ОБЩИЕ ЭЛЕМЕНТЫ

Общие элементы - элементы, которые часто повторяются в семействах.

### УГО

УГО – условные графические элементы. На разных уровнях детализации отображается разное УГО.

**Высокий уровень детализации** – геометрия светильника выглядит точно так же, как и 3д.

**Средний уровень детализации** – масштаб УГО не зависит от реальных размеров светильника. Размеры УГО можно менять по экземпляру.

**Низкий уровень детализации** – размер УГО зависит от реальных размеров светильника.

![Светильники для Revit. Инструкция — УГО](./img-02.jpg)

![Светильники для Revit. Инструкция — УГО](./img-03.jpg)

Используйте любой удобный вам уровень детализации.

Чтобы менять стиль УГО светильников нужно перейти в (для Среднего уровня детализации): **Управление** > **Стили объектов** > **Объекты аннотаций** > **Типовые аннотации** > **INT 07 Светильники УГО**

![Светильники для Revit. Инструкция — УГО](./img-04.jpg)

Размер (масштаб) УГО на среднем уровне детализации можно изменить по экземпляру через параметр **УГО(СР)Размер**.

![Светильники для Revit. Инструкция — УГО](./img-05.jpg)

Также конкретно для группы семейств Бра есть отдельный параметр **Высота УГО План**. Он нужен чтобы поднять само УГО выше над мебелью, если данная мебель перекрывает бра на плане.

### Подзаголовки и работа с семействами

В каждом семействе светильников есть основные подзаголовки в Свойствах:

- **Графика : Видимость, Опции.**
  - В подразделе **Видимость** можно вкл/выкл элементы семейства.
  - **Опции** - выбираем нужную форму/тип/направление/кол-во элементов.

- **Материалы и отделка.**
- **Размеры : Габариты, Размещение, Размеры элементов.**
  - В подразделе **Габариты** показаны габаритные размеры светильника. Чаще всего они серого цвета, т.е. не редактируемые, а считаются автоматически по формулам.
  - **Размещение** - управление разными сдвигами, смещениями, поворотами.
  - **Размеры элементов** - управление всеми возможными размерами (высота, ширина, толщина, диаметр).

![Светильники для Revit. Инструкция — Подзаголовки и работа с семействами](./img-06.jpg)

Параметры можно менять путём перещёлкивания галочек или выбора из выпадающего списка.

![Светильники для Revit. Инструкция — Подзаголовки и работа с семействами](./img-07.jpg)

### Торшеры

Группа с торшерами включает в себя несколько семейств:

- Торшер
- Торшер-журавль
- Торшер с выносом плафона

![Светильники для Revit. Инструкция — Торшеры](./img-09.jpg)

Торшер это стандартный осветительный прибор, который можно разместить на тумбу, стол или на пол.

**П_Глубина** работает при форме плафона Прямоугольник.

**П_Высота** фикс при форме плафона Шар (т.е. равен параметру **П_Ширина** и всё управление размерами плафона работает именно через **П_Ширина**).

А когда форма плафона Полусфера, то между **П_Высота** и **П_Ширина** есть такая зависимость: **П_Ширина**/2= **П_Высота**.

![Светильники для Revit. Инструкция — Торшеры](./img-10.jpg)

В семействе Торшер-журавль есть отличие от просто Торшера в виде угла поворота стойки торшера.

![Светильники для Revit. Инструкция — Торшеры](./img-11.jpg)

В семействе Торшер с выносом плафона есть отличие от просто Торшера в виде доп.опции по выносу плафона в сторону от центральной стойки и размещение плафона вверх или вниз.

![Светильники для Revit. Инструкция — Бра](./img-12.jpg)

### Подвесы

Группа с подвесами включает в себя несколько семейств:

- Подвес
- Подвес линейный
- Подвес арочный
- Подвес облако (нужен чтобы показать большой объёмный светильник сложных форм, который бы показал габариты в пространстве без детального моделирования средствами Revit)

Семейство Подвес – это базовое семейство в этой группе, в котором есть различные варианты плафонов, креплений на плафоне, формы и размеры.

![Светильники для Revit. Инструкция — Подвесы](./img-17.jpg)

**Часть плафона**. 100%=**П_Высота**. Используется в круглых формах плафона (шар, шар усечённый, колпачок).

![Светильники для Revit. Инструкция — Подвесы](./img-18.jpg)

Типы подвеса: 5 плафонов и 7 плафонов. В данных случаях плафоны имеют форму только шара и они равномерно размещаются по каркасу. Их кол-во не меняется, только размер.
Но если выбрать тип Массив, то мы сможем редактировать параметры в Опциях Массива.

Если выбран тип Массив и **Подвес высота**=0, то провод подвеса и заглушка выключаются и остаётся только Подвес-массив (или, другими словами, накладной подвес с возможностью редактирования). Его высота управляется параметром **Подвес-массив высота**.

Параметры **Слева** и **Справа** работают при **Кол-ве заглушек**: Две. А если выбрано кол-во Одна - используем размер **Ширина между проводами**. Заглушка изменяется вместе с этим параметром. Размер **Заглушка глубина слева** управляет глубиной.

![Светильники для Revit. Инструкция — Подвесы](./img-19.jpg)

Для квадратных ламп глубина лампы определяется по формуле (**Коробка ширина** - **Коробка ширина рамки**\*2)/ **Лампа количество**.

Параметр **Лампа высота от потолка** определяет глубину размещения ламп относительно верхней грани коробки. Значение параметра может быть как положительным, так и отрицательным.

### Профиль

Состоит из одного светильника - LED профиля.

![Светильники для Revit. Инструкция — Профиль](./img-28.png)

У встроенного профиля по умолчанию вырезается отверстие.

При необходимости, отверстие отключается с помощью параметра **Отверстие под встроенный профиль**.

На плане при низком уровне детализации у профиля появляются обозначения Начало +/- и Конец +/-. Эти обозначения помогают при настройке Подрезки.

Обозначения можно отключить параметром **УГО_Начало_Конец**.

Длиной профиля управляет параметр **Длина (вручную)**. Длина профиля также регулируется ручками на 3D-виде и на плане.

![Светильники для Revit. Инструкция — Профиль](./img-29.png)

Значение Без подрезки включает заглушки на концах профиля и подрезает профиль под прямым углом.

Подрезка + подрезает профиль под заданным углом. Острие угла направлено в сторону + на плане.

В параметр **П_Конец угол** вводится значение угла между 2-мя стыкуемыми профилями Доступное значение угла: от 10° до 170°.

Подрезка - подрезает профиль под заданным углом. Острие угла направлено в сторону - на плане.

Подрезка Вперед используется для стыка 2-х профилей под прямым углом в разных плоскостях (внутрь).

### Трековые светильники

Группа с трековыми светильниками включает в себя несколько семейств:

- Трек встроенный
- Трек накладной
- Трек радиусный встроенный
- Трек радиусный накладной
- Трековый светильник - Линейный поворотный
- Трековый светильник - Линейный
- Трековый светильник - Точечный

![Светильники для Revit. Инструкция — Трековые светильники](./img-30.png)

У встроенного трека по умолчанию вырезается отверстие.

При необходимости, отверстие отключается с помощью параметра **Отверстие под трек**.

Для отверстий трека под соединители Угол внутренний и Угол внешний в стыках стена-стена и стена-потолок, необходимо дополнительно воспользоваться инструментом Вырезать на панели инструментов.

Длиной у всех треков управляет параметр **Длина (вручную)**. Длина также регулируется ручками на 3D-виде и на плане.

![Светильники для Revit. Инструкция — Трековые светильники](./img-31.png)

Параметры **Подвес начало высота** и **Подвес конец высота** задают крепление подвеса к наклонной плоскости.

Расстояние от трека до точки крепления берется по наибольшему значению.

Отступ подвесов от краёв трека задаётся параметром **Подвес отступ от края**.

Чтобы включить видимость подвесов используются параметры **П_Начало** и **П_Конец**.

Чтобы включить видимость проводов используются параметры **Пр_Начало** и **Пр_Конец**.

![Светильники для Revit. Инструкция — Трековые светильники](./img-32.png)

На плане при низком уровне детализации в режиме Каркас у трека появляются обозначения Начало +/- и Конец +/-.

Эти обозначения помогают при выборе типа соединителя в параметрах (С) Соединитель: **С_Начало** и **С_Конец**.

Соединители:

#### Заглушка

Соединитель Заглушка можно устанавливать как для **С_Начало**, так и для **С_Конец** на концах трека.

#### Без соединителя

Стоит выбрать, если трек стыкуется с соединителем соседнего трека.

В редких случаях, когда трек обоими концами стыкуется с Конец +/- других треков, допустимо выбирать тип соединителя **С_Конец**: Без соединителя.

#### Соединитель X

Соединитель Конец: Соединитель X используется для стыка четырех треков под прямым углом.

![Светильники для Revit. Инструкция — Трековые светильники](./img-33.png)

#### Соединитель Угловой

Соединитель Конец: Соединитель Угловой используется для стыка двух треков под углом. Угол задаётся в параметре **С_Угол**.

Если активен параметр **С_Угол -**, то острие угла на плане направлено в сторону минуса.

Если активен параметр **С_Угол +**, то острие угла на плане направлено в сторону плюса.

#### Стык на прямом участке

Соединитель Без соединителя : Стык на прямом участке служит для соединения нескольких треков на прямой. Можно использовать в случаях, когда трек в проекте достаточно длинный и должен состоять из нескольких прямых элементов.

#### Соединитель Т

Соединитель Конец: Соединитель Т используется для стыка трех треков под прямым углом.

Если активен параметр **С_Угол +**, то один свободный конец соединителя направлен в сторону плюса. Чтобы отзеркалить элемент, возле Начала трека размещен элемент управления ↓↑.

![Светильники для Revit. Инструкция — Трековые светильники](./img-34.png)

#### Внешний угол

Соединитель Конец: Внешний угол используется для стыка 2-х треков под прямым углом в разных плоскостях (наружу).

Для стыка с соединителем Конец: Внешний угол, в параметре **С_Начало** необходимо выбрать значение Без соединителя: Стык на прямом участке

#### Внутренний угол

Соединитель Конец: Внутренний угол используется для стыка 2-х треков под прямым углом в разных плоскостях (внутрь).

Для стыка с соединителем Конец: Внутренний угол, в параметре **С_Начало** необходимо выбрать значение Без соединителя: Стык на прямом участке.

![Светильники для Revit. Инструкция — Трековые светильники](./img-35.png)

Параметры **Наклонная основа** позволяют отобразить на плане светильник, который размещается на наклонном треке. Чтобы условное обозначение было видно на плане, параметр **УГО на наклонной поверхности** должен быть активен.

На низком уровне детализации размер УГО зависит от размера светильника.

На среднем уровне детализации необходимо задать значение масштаба плана для параметра **Масштаб плана** и задать желаемый размер УГО на листе для параметра **УГО размер наклонная основа**.

В случаях, когда трековые светильники необходимо разместить не на потолке или крыше, а на стене, необходимо сделать активным параметр **УГО на стене**.

Размер УГО на средней детализации также будет управляться параметром **Масштаб плана** и **УГО размер наклонная основа**.

## 5. УГО и Figma

Для набора светильников были добавлены изображения всех УГО по типу в параметры **Условное обозначение** и **Условное обозначение 2**.

В случае, если вам необходимо изменить УГО в спецификации, вы можете отредактировать векторный файл с изображением светильника на страничке в Figma.

ссылка на Figma:

https://www.figma.com/design/Wmf24tLPX4jthdiSWlPSOY/INT-LIGHTING?node-id=4-277&t=zR6X0GsaoMQxt9ry-0

Просмотр файлов доступен в любом браузере, но редактировать на странице от INT LINES нельзя, нужно выделить всё и скопировать к себе на страницу.

<u>Алгоритм замены изображения в проекте:</u>

- Чтобы загрузить обновлённое изображение в семейство необходимо найти в Диспетчере проекта нужное семейство и нажать Правка. Вы попадёте в редактор семейства.
- Здесь вам нужно открыть окно Типоразмеры в семействе и заменить значения параметров **INT_Условное обозначение** для низкого уровня детализации или **INT_Условное обозначение 2** для среднего уровня.
- После этого необходимо загрузить семейство в проект и выбрать !!!Заменить существующую версию и значения параметров!!!
