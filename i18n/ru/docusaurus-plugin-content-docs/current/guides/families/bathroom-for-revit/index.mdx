## 1. ОБЩИЕ ДАННЫЕ

-   Название набора: Сантехника
-   Версия набора 1.3.0
-   Версия Revit: 2019

### Описание

Набор семейств сантехники для Revit предназначен для работы в Autodesk Revit и использования в BIM-проектах интерьеров и архитектуры. Библиотека включает параметрические семейства сантехнического оборудования, разработанные с учетом точных размеров и требований к проектированию санузлов и постирочных.

С помощью семейств можно создавать и настраивать ванны, раковины, душевые кабины, душевые системы, смесители, полотенцесушители, сантехническое оборудование и аксессуары для ванных комнат.

Набор предназначен для дизайнеров интерьера, архитекторов и проектировщиков, работающих в Autodesk Revit над жилыми и общественными объектами.

### Загрузка и размещение

Для того чтобы посмотреть и загрузить нужные семейства из набора, можно открыть **Проект с сантехническими приборами** и скопировать семейства при помощи комбинации клавиш Ctrl+C, а затем вставить в свой проект Ctrl+V. Или открыть папку с файлами семейств и перетащить мышкой в проект.

## 3. СЕМЕЙСТВА

### УГО Выводы

![Сантехника для Revit — УГО Выводы](./img-13.png)

На виде сверху на **среднем** уровне детализации можно включить условно-графическое обозначение (УГО) выводов воды, чтобы показать, какие трубы нужно подводить к этому участку.

Чтобы включить УГО, необходимо выполнить следующие шаги:

1. В свойствах в группировании **Графика** поставить галочку на параметр видимости “**УГО**”.

2. Изменить уровень детализации вида на **средний**.

![Сантехника для Revit — УГО Выводы](./img-14.png)

Отображение УГО на виде сверху зависит от того, какие системы включены в параметрах Графики внутри родительского семейства для УГО Выводы, а также от параметра “Вертикальное размещение”.

Условные обозначения по типу системы:

-   Синий - холодное водоснабжение
-   Красный - горячее водоснабжение
-   Зеленый - канализация

![Сантехника для Revit — УГО Выводы](./img-15.png)

На виде спереди УГО выводов в семействах выполнено в виде круговых маркеров с осевыми линиями.

Цвет маркеров также обозначает тип системы.

Отображение УГО зависит от включенных параметров по типу системы и параметра “Вертикальное размещение”.

### Параметры УГО Выводы. Общие размеры

![Сантехника для Revit — Параметры УГО Выводы. Общие размеры](./img-16.png)

В подгруппе **УГО** в группировании **Размеры** расположены параметры, управляющие размерами и положением условно-графического обозначения относительно элементов родительского семейства.

Параметры, встречающиеся в семействах:

-   УГО ХВ и ГВ высота: высота вывода холодной и горячей воды
-   УГО канализации высота: высота вывода канализации
-   УГО ХВ и ГВ диаметр: диаметр окружностей УГО холодной воды и горячей воды
-   УГО канализации диаметр: диаметр окружности УГО канализации
-   УГО ось воды смещение: смещение вывода холодной воды (или холодной и горячей воды) от канализации

##### Размеры

![Сантехника для Revit — Размеры](./img-19.png)

Параметры “INT_Ширина”, “INT_Глубина” и “INT_Высота” управляют габаритами ванной.

“Ножки сдвиг вверх вниз”: Расстояние ножек от края по короткой стороне.

“Ножки сдвиг слева/справа”: Расстояние ножек от края по длинной стороне ванны.

“Чаша высота”: Расстояние от дна ванны до края бортика. Изменяется за счет высоты ножек.

“Бортик ширина”: Ширина от внутреннего края чаши до внешнего края ванны.

![Сантехника для Revit — Опции](./img-127.png)

В семействе смесителя доступны опции для лейки, типа шланга и основания.

При включенном параметре “Лейка” доступны:

Выбор формы лейки:

-   Лейка форма цилиндр
-   Лейка форма круг
-   Лейка форма прямоугольник

Также доступен выбор типа шланга:

-   Шланг тип ванна
-   Шланг тип душ

При включенном параметре “Основание” доступен выбор формы смесителя:

-   Основание форма прямоугольник
-   Основание форма овал

#### Смеситель классический

![Сантехника для Revit — Смеситель классический](./img-128.png)

В семействе доступен выбор типа смесителя:

-   1 тип на борт
-   2 тип напольный
-   3 тип настенный

##### Размеры

![Сантехника для Revit — Размеры](./img-129.png)

Параметр “Высота размещения” доступен только для смесителя при включенном параметре “2 тип напольный”. Для смесителей “1 тип на борт” и “3 тип настенный” изменять высоту можно с помощью инструмента “Смещение” в проекте Revit.

Параметр “Расстояние между осями” задает расстояние между центрами (осями) вентилей и работает для всех типов смесителей.
