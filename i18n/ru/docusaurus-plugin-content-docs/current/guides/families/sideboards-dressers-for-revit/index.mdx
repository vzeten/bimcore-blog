## 1. ОБЩИЕ ДАННЫЕ

-   Название набора: Тумбы и комоды
-   Версия набора 1.0.0
-   Версия Revit: 2019

### Описание

Этот набор семейств для Revit предназначен для моделирования тумб и комодов в Autodesk Revit.

С помощью семейств можно создать тумбы и комоды различной конфигурации по точным размерам.

Подходит дизайнерам интерьера и архитекторам. Для моделирования тумб и комодов мебельщиками семейства недостаточно детализированные.

### Загрузка и размещение

Для того чтобы посмотреть и загрузить нужные семейства из набора, можно открыть **Проект тумб и комодов** и скопировать семейства при помощи комбинации клавиш Ctrl+C, а затем вставить в свой проект Ctrl+V. Или открыть папку с файлами семейств и перетащить мышкой в проект.

## 4. СЕМЕЙСТВА

### Комод

Семейство Комод используется для построения комодов различной конфигурации.

![Тумбы и комоды для Revit — Комод](./img-06.jpg)

Здесь можно включить/выключить следующие элементы:

-   Модуль 2
-   Ручки модуля 1
-   Ручки модуля 2
-   Столешница
-   Бортик
-   Ножки
-   Царги ножек

#### Опции комода

![Тумбы и комоды для Revit — Опции комода](./img-07.jpg)

Количество фасадов может быть от 1 и более.

Ширина фасадов не задаётся, а считается автоматически.

В подсказках параметров есть информация о минимальных и максимальных значениях (для этого нужно навести мышку на нужный параметр и подождать, тогда и появится подсказка)

Модуль 1

1 Кол-во столбцов: от 1 до 2

1 Кол-во ящиков: от 1 и более

Модуль 2

2 Кол-во столбцов: от 1 до 4

2 Кол-во ящиков: от 1 и более

Количество ящиков по высоте может быть от 1 и более, но нужно следить за корректностью по размерам, чтобы не появилась ошибка.

#### Размеры

![Тумбы и комоды для Revit — Размеры](./img-08.jpg)

Комод высота - это параметр высоты, в котором есть другие мелкие высоты элементов, если они включены по галочке (Ножки высота, Модуль 2 высота, Столешница толщина, Бортик высота).

Есть параметры серого цвета, которыми нельзя управлять. Но они нужны для понимания расчётов размеров. Например, *Размер_ширина*. Параметр показывает общую ширину мебели, т.к.она считается по формуле исходя из размера выступа столешницы и ширины самого комода.

Если столешница выключена, *Размер_ширина* будет равняться *Комод ширина*. Тот же принцип относится и к глубине комода.

![Тумбы и комоды для Revit — Размеры](./img-09.jpg)

Ручки типа вырез, скоба и накладная имеют возможность менять свою ширину. Ручки типа вырез и накладная всегда расположены по центру верхнего края фасада.

Параметр *Сдвиг ручек от края*  влияет на вертикальное расположение ручек.

![Тумбы и комоды для Revit — Размеры](./img-10.jpg)

Размеры ножек Классика фиксированные:

Ножки ширина = 40мм

Ножки высота = 150мм

Параметр *Сдвиг ножек по бокам* и *Сдвиг ножек вперед/назад* влияет на перемещение ножек к центру комода.

#### Фасады

![Тумбы и комоды для Revit — Фасады](./img-11.jpg)

У модуля 2 есть возможность отключения фасадов, что создает полку в верхней части комода. Полка может быть только одна, количество вертикальных перекладин зависит от выбора количества столбцов в модуле 2.

#### Ручки

![Тумбы и комоды для Revit — Ручки](./img-12.jpg)

У модуля 1 и модуля 2 ручки отключаются/включаются и меняются по отдельности.

Ручка может быть одна или две на одном фасаде. Это не касается ручек формы Вырез и Накладная, их всегда по одной на одном фасаде.

Если убрать галочку с параметра “Ручки по центру”, тогда они переместятся к верхней границе фасада. И в разделе “Размеры” появится возможность регулировать расстояние ручки от верхнего края фасада.

### Тумба

Семейство Тумба используется для построения тумб различной конфигурации.

![Тумбы и комоды для Revit — Тумба](./img-14.jpg)

Здесь можно включить/выключить следующие элементы:

-   Столешница
-   Ручки
-   Ножки
-   Царги ножек
-   Заглушка слева
-   Заглушка справа
-   Перегородки
-   Открывание

Фасады и ручки одинаковы для всех модулей. Отдельно для одного модуля меняются:

-   Фасады кол-во
-   Размещение ручки
-   Вертикально(для ручки)
-   Открывание

#### Опции тумбы

![Тумбы и комоды для Revit — Опции тумбы](./img-15.jpg)

У тумбы настраивается количество модулей от 1 до 5. Они могут быть равнозначны или настраиваться по отдельности. Ширина каждого модуля настраивается по отдельности, кроме Модуля 1. Оно рассчитывается вычитанием общей ширины модулей со 2 по 5 из общего размера тумбы.

![Тумбы и комоды для Revit — Опции тумбы](./img-16.jpg)

Каждый модуль в тумбе настраивается по отдельности.

![Тумбы и комоды для Revit — Опции тумбы](./img-17.jpg)

Заглушки справа и слева включаются по отдельности, но высота настраивается совместно.

Между модулей есть возможность включить дополнительную перегородку, позволяющая создавать больше конфигураций тумб.

#### Размеры

![Тумбы и комоды для Revit — Размеры](./img-18.jpg)

Тумба высота - это параметр высоты, в котором есть другие мелкие высоты элементов, если они включены по галочке (Ножки высота, Столешница толщина).

Есть параметры серого цвета, которыми нельзя управлять. *Модуль 1 ширина* нельзя управлять для правильности работы всего семейства. Размеры начинающиеся с *ADSK* являются общими и могут быть использованы в спецификациях при необходимости.

Если столешница выключена, *ADSK_Размер_Ширина*  будет равняться *Тумба ширина*. Тот же принцип относится и к глубине комода.

![Тумбы и комоды для Revit — Размеры](./img-19.jpg)

Ручки типа вырез, скоба и накладная имеют возможность менять свою ширину. Ручки типа вырез и накладная всегда расположены по центру верхнего края фасада.

Параметр *Сдвиг ручек от края*  влияет на вертикальное расположение ручек.

![Тумбы и комоды для Revit — Размеры](./img-20.jpg)

Размеры ножек Классика фиксированные:

Ножки ширина = 40мм

Ножки высота = 150мм

Параметр *Сдвиг ножек по бокам* и *Сдвиг ножек вперед/назад*  влияет на перемещение ножек к центру комода.

#### Фасады открывание

![Тумбы и комоды для Revit — Фасады открывание](./img-21.jpg)

Тип открывания фасадов каждого модуля настраивается отдельно.

Тип открывания:

1 - Левое открывание

2 - Выдвижной ящик

3 - Правое открывание

4 - Откидной вниз

#### Ручки расположение

![Тумбы и комоды для Revit — Ручки расположение](./img-22.jpg)

Для каждого модуля настраивается расположение ручек и ориентация.

### Тумба овальная

Семейство Овальная тумба используется для построения тумб различной конфигурации со скругленными углами.

![Тумбы и комоды для Revit — Тумба овальная](./img-25.jpg)

Здесь можно включить/выключить следующие элементы:

-   Бортик
-   Интегрированные ручки

Так же в данном разделе настраивается:

-   Тип фасада и их количество
-   Расположение столешницы
-   Форма ножек

#### Размеры

![Тумбы и комоды для Revit — Размеры](./img-26.jpg)

Тумбочка высота - это параметр высоты, который включает в себя параметр *Бортик*, если он включен в графике.

Есть параметры серого цвета, которыми нельзя управлять. Размеры начинающиеся с *ADSK* являются общими и могут быть использованы в спецификациях при необходимости.

#### Фасады

![Тумбы и комоды для Revit — Фасады](./img-27.jpg)

При выборе фасадов тип *Ящик* или *Дверца*, их количество можно менять. При выборе *Фасад полка*, фасад нижнего ящика всегда один.

![Тумбы и комоды для Revit — Фасады](./img-28.jpg)

Любой тип фасада может иметь интегрированную ручку.

![Тумбы и комоды для Revit — Фасады](./img-29.jpg)

При выборе параметров *Столешница + зазор внутри/Столешница + смещение вверх*, в разделе **Размеры** появляется возможность редактировать смещение столешницы.

#### Ножки

![Тумбы и комоды для Revit — Ножки](./img-30.jpg)

В выпадающем списке форма ножек:

-   Прямоугольник
-   Цилиндр
-   Конус
-   Конус под углом
-   Платформа

![Тумбы и комоды для Revit — Ножки](./img-31.jpg)

Параметр *Сдвиг ножек по бокам* и *Сдвиг ножек вперед/назад*  влияет на перемещение ножек к центру комода.
