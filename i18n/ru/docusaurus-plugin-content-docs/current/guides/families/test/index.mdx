## 1. ОБЩИЕ ДАННЫЕ

-   Название набора: Семейства Кухня
-   Версия набора 3.2.1
-   Версия Revit: 2019

### Описание

Этот набор семейств для Revit предназначен для моделирования кухни в Autodesk Revit.

С помощью семейства можно создать кухню по точным размерам и посчитать количество модулей кухни.

Подходит дизайнерам интерьера и архитекторам. Для моделирования кухни мебельщиками семейства недостаточно детализированные.

### Загрузка и размещение

Для того чтобы посмотреть и загрузить нужные семейства из набора, можно открыть Проект с кухней и скопировать семейства при помощи комбинации клавиш Ctrl+C, а затем вставить в свой проект Ctrl+V. Или открыть папку с файлами семейств и перетащить мышкой в проект.

## 3. ОБЩИЕ ЭЛЕМЕНТЫ

В этом разделе вы узнаете из каких элементов состоят модули и как их настраивать.

### Общие элементы

Общие элементы - элементы, которые повторяются в каждом кухонном модуле.

Общими элементами всех кухонных модулей являются:

-   Фасады
-   Ручки
-   Ножки
-   Открывание
-   Корпус
-   Задняя стенка (часть корпуса)
-   Левый торец (часть корпуса)
-   Правый торец (часть корпуса)

### Фасады

Типы фасадов можно выбрать в выпадающем списке у каждого семейства модуля. Это:

-   Нет фасада
-   Стандарт
-   Рамка внутри
-   Рамка снаружи
-   С интегрированной ручкой сверху
-   С интегрированной ручкой слева
-   С интегрированной ручкой справа
-   С интегрированной ручкой снизу

### Ручки

#### Типы ручек

Типы ручек можно выбрать в выпадающем списке у каждого семейства модуля. Это:

-   Нет ручек
-   Скоба
-   Накладная
-   Кнопка
-   Т-образная

Для накладной ручки нужно поставить значение параметра РУ.Сдвиг =2мм, чтобы она сдвинулась на край фасада.

У Т-образной ручки меняется отображение при разной длине ручки (РУ.Длина).

#### Размещение ручек

Размещение ручек сделано цифрами от 1 до 9. Визуально это похоже на размещение цифр на клавиатуре.

Ещё можно посмотреть подсказку в самом параметре РУ.Размещение.

Положение ручек может быть горизонтальным и вертикальным. За это отвечает параметр РУ.Горизонтально.

### Открывание

#### Типы открывания

Типы открывания можно выбрать в выпадающем списке у каждого семейства модуля. Это:

-   Нет открывания
-   Левое
-   Правое
-   Вниз
-   Вверх
-   Ящик
-   Двойное
-   Левый сдвиг
-   Правый сдвиг
-   Двойной сдвиг
-   Подъемное
-   Подъемное наклонное
-   Складное
-   2 ящика

Открывание фасадов не зависит от положения ручек.

#### Разные виды открывания RU / ENG

Чтобы включить Открывание RU или ENG, необходимо зайти в Видимость вида, далее в Мебель и там выбрать нужный вам вид открывания.

### Торцы

Торцы слева (Л) и справа (П) есть во всех корпусах модулей и их можно выключить, если нужно. Но по умолчанию они включены.

Л.Торец, П.Торец -  добавляют дополнительную панель сбоку и закрывают торец фасада.

В модулях, которые устанавливаются на пол, добавляются дополнительные параметры к торцам. Это: Л.До пола,П.До пола (что позволяет опустить торцы до пола) и Л.Торец, П.Торец.

## 4. СЕМЕЙСТВА

### Нижний модуль

Нижний модуль используется для построения шкафов кухни, которые размещаются на полу и являются рабочей поверхностью при готовке.

Здесь можно включить/выключить следующие элементы:

-   Столешница
-   Ручки
-   Фасады
-   Корпус
-   Задняя стенка
-   Полка
-   Скрытый ящик (отображается штриховой линией)
-   Ножки
-   ручки Gola
-   разные опции Торцов, про которые говорилось ранее
