## 1. ОБЩИЕ ДАННЫЕ

- Название набора: Мебель для ванной
- Версия набора 1.1.0
- Версия Revit: 2019

### Описание

Этот набор семейств для Revit предназначен для моделирования мебели для ванных комнат в Autodesk Revit.

С помощью семейств можно создать тумбы с раковиной и без, подвесные шкафы с зеркалом, пеналы, стеллажи и прочее различной конфигурации по точным размерам.

Подходит дизайнерам интерьера и архитекторам. Для моделирования корпусной мебели мебельщиками семейства недостаточно детализированные.

### Загрузка и размещение

Для того чтобы посмотреть и загрузить нужные семейства из набора, можно открыть **Проект с мебелью для ванной** и скопировать семейства при помощи комбинации клавиш Ctrl+C, а затем вставить в свой проект Ctrl+V. Или открыть папку с файлами семейств и перетащить мышкой в проект.

## 3. СЕМЕЙСТВА

### Тумба с раковиной

Семейство Тумба с раковиной используется для построения тумб различной конфигурации.

![Мебель для ванной для Revit — Тумба с раковиной](./img-02.jpg)

Здесь можно включить/выключить следующие элементы:

- Столешница
- Смеситель
- Раковина
- Фасады
- Планка
- Ручки
- Сифон
- Задняя стенка каркаса
- Ножки
- Открывание
- УГО

#### Размеры

![Мебель для ванной для Revit — Размеры](./img-03.jpg)

Тумба высота - это параметр высоты, в котором есть другие мелкие высоты элементов, если они включены по галочке (Ножки высота, Планка высота, Столешница толщина).

![Мебель для ванной для Revit — Размеры](./img-04.jpg)

Размеры начинающиеся с *INT* являются общими и могут быть использованы в спецификациях при необходимости.

![Мебель для ванной для Revit — Размеры](./img-05.jpg)

Ручки типа вырез, скоба и накладная имеют возможность менять свою ширину. Ручки типа вырез и накладная всегда расположены по центру верхнего края фасада.

![Мебель для ванной для Revit — Размеры](./img-06.jpg)

Параметр *Ножки сдвиг по бокам* и *Ножки сдвиг вперед/назад*  влияет на перемещение ножек к центру тумбы.

#### Фасады

![Мебель для ванной для Revit — Фасады](./img-07.jpg)

У тумбы может быть два типа расположения фасадов в виде двух дверец, либо два ящика.

![Мебель для ванной для Revit — Фасады](./img-08.jpg)

В выпадающем списке типа фасадов:

- Стандарт (ровный фасад)
- Рамка (фасад с внешней рамкой)
- С интегрированной ручкой

![Мебель для ванной для Revit — Фасады](./img-09.jpg)

Все типы фасадов могут быть внутренними и наружными.

![Мебель для ванной для Revit — Фасады](./img-10.jpg)

При включенной видимости *Открывание*, необходимо выбрать тип открывания в соответствии с типом расположением фасадов.

#### Ручки

![Мебель для ванной для Revit — Ручки](./img-11.jpg)

В данном разделе можно выбрать форму ручек:

- Кнопка
- Вырез
- Скоба
- Накладная

Если убрать галочку с параметра “Размещение по центру”, тогда они переместятся к верхней границе фасада. И в разделе “Размеры” появится возможность регулировать расстояние ручки от верхнего края фасада.

#### Ножки

![Мебель для ванной для Revit — Ножки](./img-12.jpg)

У тумбы есть два типа ножек: Прямоугольник и Цилиндр. У тумбы можно отключить все ножки или только задние.

#### Материалы

![Мебель для ванной для Revit — Материалы](./img-13.jpg)

#### Настройки графики

![Мебель для ванной для Revit — Настройки графики](./img-14.jpg)

Чтобы поменять цвет/вес/тип или выключить отображение открывания линий семейства, нужно перейти в Управление - Стили объектов - Мебель/Сантехнические приборы

### Зеркало-шкаф

Семейство Зеркало-шкаф используется для построения подвесных шкафов различной конфигурации.

![Мебель для ванной для Revit — Зеркало-шкаф](./img-15.jpg)

Здесь можно включить/выключить следующие элементы:

- Секция слева
- Секция справа
- Полка снизу

#### Размеры

![Мебель для ванной для Revit — Размеры](./img-16.jpg)

Размеры начинающиеся с *INT* являются общими и могут быть использованы в спецификациях при необходимости.

#### Опции шкафа

![Мебель для ванной для Revit — Опции шкафа](./img-17.jpg)У шкафов настраивается количество секций. Они могут быть равнозначны или настраиваться по отдельности. Ширина каждой секции настраивается по отдельности. У боковых секций может быть фасад, 2 или 3 полки. Секции настраиваются вне зависимости друг от друга.

![Мебель для ванной для Revit — Опции шкафа](./img-18.jpg)

У центральной секции зеркало может располагаться в 3 вариантах: на корпусе (как фасад), в корпусе (образуя полку), без корпуса (зеркало на стене, может быть с одной или двумя боковыми секциями).

#### Материалы

![Мебель для ванной для Revit — Материалы](./img-19.jpg)

### Пенал

Семейство Пенал используется для построения узких шкафов различной конфигурации.

![Мебель для ванной для Revit — Пенал](./img-20.jpg)

Здесь можно включить/выключить следующие элементы:

- Фасады
- Ручки
- Ножки
- Открывание

#### Размеры

![Мебель для ванной для Revit — Размеры](./img-21.jpg)

Размеры начинающиеся с *INT* являются общими и могут быть использованы в спецификациях при необходимости.

![Мебель для ванной для Revit — Размеры](./img-22.jpg)

Ручки типа скоба имеют возможность менять свою ширину.

![Мебель для ванной для Revit — Размеры](./img-23.jpg)

Параметр *Ножки сдвиг по бокам* и *Ножки сдвиг вперед/назад*  влияет на перемещение ножек к центру тумбы.

#### Фасады

![Мебель для ванной для Revit — Фасады](./img-24.jpg)

У пенала настраивается количество модулей от 1 до 3. Они могут быть равнозначны или настраиваться по отдельности. Высота каждого модуля настраивается по отдельности, кроме Модуля 3. Оно рассчитывается вычитанием общей высоты модулей 1 и 2 из общего размера пенала.

![Мебель для ванной для Revit — Фасады](./img-25.jpg)

В выпадающем списке типа фасадов:

- Стандарт (ровный фасад)
- Рамка (фасад с внешней рамкой)

![Мебель для ванной для Revit — Фасады](./img-26.jpg)

Каждый модуль в тумбе настраивается по отдельности.

![Мебель для ванной для Revit — Фасады](./img-27.jpg)

Тип открывания фасадов каждого модуля настраивается отдельно.

Тип открывания:

1 - Левое открывание

2 - Выдвижной ящик

3 - Правое открывание

4 - Откидной вниз

#### Ручки

![Мебель для ванной для Revit — Ручки](./img-28.jpg)

У данного семейства есть два типа ручек: кнопка и скоба. Ручка типа скоба может менять ориентацию между вертикальной и горизонтальной.

![Мебель для ванной для Revit — Ручки](./img-29.jpg)

Для каждого фасада настраивается расположение ручек и их ориентация при выборе ручки скоба.

#### Ножки

![Мебель для ванной для Revit — Ножки](./img-30.jpg)

В выпадающем списке форма ножек:

- Прямоугольник
- Цилиндр
- Цоколь
- Каркас до пола
