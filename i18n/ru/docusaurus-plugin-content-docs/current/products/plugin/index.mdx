Разработка INT LINES.

В плагине BIMCORE дизайнеры интерьера находят и размещают приобретённые семейства INT LINES / BIMCORE прямо в Revit 2019–2027. Откройте проект набора или выберите отдельное семейство для своего проекта.

**[Установить плагин](/guides/bimcore-plugin/installation)**

## Что бесплатно

Плагин и его базовые возможности бесплатны. Наборы семейств и интерьерный шаблон продаются отдельно. После входа доступны бесплатные семейства для пробы.

## Уже приобрели набор

Приобретённые наборы появятся в панели плагина после входа с почтой, указанной в заказе.

## Плагин, семейства и шаблон

В [интерьерном шаблоне INT LINES](/guides/templates/) уже настроены виды, листы и ведомости для рабочей документации. Шаблон совместим с семействами INT LINES. Через плагин размещайте семейства в проекте на основе шаблона.

Выбрать наборы можно в магазинах [BIMCORE](https://bimcore.one/) и [INT LINES](https://int-lines.com/revit-families/).

## Как начать

1. [Установите плагин](/guides/bimcore-plugin/installation) и откройте его в Revit.
2. [Зарегистрируйтесь и войдите](/guides/bimcore-plugin/sign-in) с паролем из письма «BIMCORE Revit Add-in».
3. [Откройте проект набора кнопкой **Открыть** или разместите семейство кнопкой **Разместить**](/guides/bimcore-plugin/sets).
4. [Найдите семейство, откройте карточку набора и выберите язык семейств](/guides/bimcore-plugin/panel).

Если нужно обновить плагин, восстановить пароль или проверить доступ к наборам, откройте [вопросы и ответы](/guides/bimcore-plugin/faq). По вопросам работы плагина [напишите в поддержку в Telegram](https://t.me/IntLinesSupportBot).
