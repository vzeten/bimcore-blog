Если на плане стены из разных материалов, Revit рисует между ними линию-разделитель и две отдельные штриховки, заданные в свойствах материала. Иногда это не нужно: на общих планах хочется, чтобы стены читались как одна сплошная стена — без стыка между материалами. В этом уроке разберём, как этого добиться, не меняя сами материалы и не ломая отображение на других видах.

## Результат

На **низком уровне детализации** две стыкующиеся стены из разных материалов сольются в одну сплошную область одного цвета — без линии разделения. На **среднем** и **высоком** уровне детализации всё останется как было: разделение стен по настроенному отображению материалов.

## Шаг 1. Соедините стены инструментом «Соединить»

1. Перейдите на вкладку **Изменить**.
2. Выберите инструмент **Соединить** (Join Geometry).
3. Кликните по первой стене, затем по второй.

Геометрия стен объединится, и Revit перестанет считать их стык внешней границей. Без объединения стен следующие шаги не будут работать и линия разделения останется.

## Шаг 2. Настройте заливку при низком уровне детализации

Для каждой из соединяемых стен:

1. Выделите стену и нажмите **Изменить тип**.
2. В свойствах типа найдите параметр **Штриховка при низкой детализации** и задайте **Сплошная заливка**.
3. Выберите нужный **Цвет штриховки при низкой детализации** — например, серый.

:::tip[Совет]
Добавьте выбранный цвет в палитру (в пользовательские цвета), чтобы быстро применить тот же оттенок ко второй стене и к будущим проектам.
:::

Повторите то же самое для второй стены (в примере — стена с утеплителем): та же сплошная заливка, тот же серый цвет.

Теперь на низком уровне детализации обе стены залиты одинаково и сходятся без видимой линии стыковки, а на среднем и высоком — отображаются как настроено в свойствах материала.

## Шаг 3. Включите низкую детализацию только для стен

Часто переводить весь вид на низкий уровень детализации не нужно — остальные элементы должны остаться как есть. В этом случае можно настроить **низкий уровень детализации** только для стен:

1. Откройте **Переопределения видимости/графики** (горячая клавиша **VG** / **VV**).
2. Найдите категорию **Стены**.
3. Задайте для неё **уровень детализации** — **Низкий**.

После этого общий уровень детализации вида можно держать любым (средним, высоким), а стены на этом конкретном виде всегда будут отображаться на низком уровне — как одна сплошная стена. Настройка действует только для текущего вида и не затрагивает другие планы.

## Когда это полезно

- Общие планы, где важна форма здания, а не состав стен.
- Маркетинговые и презентационные подачи.
- Любые планы, где детализация слоёв стены отвлекает.

## Коротко

1. Соедините стены инструментом **Соединить**.
2. В типе каждой стены задайте **Сплошную заливку** одного цвета при низком уровне детализации.
3. Через **Переопределения видимости/графики** включите низкий уровень детализации только для категории **Стены**.

Готово — линия стыка между разными материалами исчезает там, где она не нужна, а все остальные элементы плана остаются с прежними настройками.
