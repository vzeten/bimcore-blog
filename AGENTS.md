## Ты проверяешь каждую правку Claude, а не только готовый блок

**Решение владельца от 2026-08-04.** Claude обязан присылать на проверку каждую законченную правку кода — починенный дефект, новую функцию, изменённую ручку API, вынесенный модуль, — не накапливая их до конца блока. Поэтому запусков будет много и они будут короткими: смотри ровно присланные файлы и ровно заявленное изменение, не разворачивая проверку на весь репозиторий.

## Консультация до кода — отдельный вид запроса

Claude обязан спросить тебя ДО написания кода, если задание затрагивает: сохранение, автосохранение, историю версий, конфликт файлов, git и развёртывание, шапку статьи, адрес статьи, локали, запись файлов, обработку ошибок, большой рефакторинг, перенос логики между модулями.

В таком запросе он показывает **замысел**, а не готовый код. Твоя задача — заранее назвать риски, крайние случаи и недостающие тесты, а не проверять реализацию. Файлы по-прежнему не меняешь. Если предлагаешь изменить смысл задания или расширить его — пометь это явно: Claude обязан сначала показать такое владельцу.

## Ревью блоков Claude — ты read-only reviewer

Claude пишет законченный блок и даёт отчёт; ты проверяешь его воротами и НЕ меняешь файлы (read-only). Запуск ревью — `codex exec --sandbox read-only` с точным списком файлов блока (не `review --uncommitted`: он не берёт промпт, а `editor/` не закоммичен → слишком широкий diff).

**Критерии и контекст — из локальных файлов репозитория, НЕ из Obsidian.** В `codex exec` вызовы MCP `obsidian` автоматически отменяются (exec неинтерактивен, подтвердить некому), поэтому автоворота на базу знаний не опираются — осознанное решение (вариант D). Всё нужное для проверки лежит в `editor/SPEC.md`, `editor/PLAN.md`, `editor/CURRENT_TASK.md` и в отчёте Claude по блоку. Читай их и проверяй по ним.

Замечания возвращаешь списком текстом — Claude правит только их. Файлы не меняешь (`--sandbox read-only` гарантирует технически), в vault ничего не пишешь.

(Стартовое чтение Obsidian по правилам выше остаётся для случаев, когда владелец поручает тебе интерактивную работу по базе, — но не для автоворот блока Claude.)
