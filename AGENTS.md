# AGENTS.md — bimcore-blog (вход для любого ИИ: Codex, Claude Code и других)

Репозиторий сайта **learn.bimcore.one** (Docusaurus). Единственный файл входа; `CLAUDE.md` рядом только
подключает этот файл. Правила ниже верны на любом компьютере, где открыт репозиторий. «Человек» ниже — тот, с кем
работает ИИ на этом компьютере.

## Статьи
Писать, править, переводить статьи и готовить картинки — по навыку
`.agents/skills/bimcore-content-editor/SKILL.md` и его папке `references/`. Это единственный источник правил
статей (стиль, структура, шапка, MDX, картинки, FAQ, карточка товара, проверки). Штатные компоненты — по
`src/theme/MDXComponents.js`, самодельный HTML вместо них не писать. Статьи публикует только редактор статей
(кнопка «Опубликовать») учётной записью того, кто вправе публиковать на сайте: он публикует сам, а ИИ — только по
его явному слову на точный состав.

## Код сайта
Код сайта (настройки, оформление, плагины, скрипты) меняют не в папке редактора, а в отдельной ветке
`fix/site-…` или `feature/site-…` от свежей `main` в копии `.worktrees/<ветка-через-дефис>`. Отправка на GitHub —
только по явному поручению владельца сайта.

## ⛔ DANGEROUS!!!!!!! — только папки вне папки проекта
- Внутри папки проекта — без вопроса: работа, скачивание, свои копии кода в `.worktrees`, свои временные папки в
  `.tmp`; установка и переустановка пакетов (`npm ci`), если они нужны для порученной работы. Это не разрешение
  удалять статьи и другие данные.
- Создавать, переносить или удалять папки вне папки проекта (системный диск, временная папка системы, профиль
  пользователя и т. д.) — только после предупреждения человека с точной пометкой **`DANGEROUS!!!!!!!`** и его явного
  согласия. Служебные записи самих программ (настройки ИИ, кэш npm) — не действие помощника. Тесты и сборку,
  которые создают временные папки, запускать с `TEMP`, `TMP` и `TMPDIR`, указывающими на `.tmp` (создать её, если нет).
- Пакеты нужны для работы, но отсутствуют или повреждены — переустановить (`npm ci`) и сказать в отчёте. Копия
  кода в `.worktrees` может собираться на пакетах основной папки, только если `package.json` и
  `package-lock.json` копии побайтно совпадают с основной папкой и установленные пакеты соответствуют lock
  (`npm ls --all` без ошибок); иначе — свои пакеты копии.

## Всегда
- Папка, с которой работает редактор статей, всегда на ветке `main`; в неё не коммитить,
  `pull`/`merge`/`reset`/`stash` не делать — редактор сам сверяет её с сайтом.
- Прямой `git push` статей запрещён.
- Это открытый репозиторий: код и внутренние документы редактора статей сюда не отправлять; ключи, токены и
  `.env*` не выводить и не коммитить.
