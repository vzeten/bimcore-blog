# AGENTS.md — bimcore-blog (вход для любого ИИ: Codex, Claude Code и других)

Репозиторий сайта **learn.bimcore.one** (Docusaurus). Единственный файл входа; `CLAUDE.md` рядом только
подключает этот файл. Решение владельца 2026-10-02.

## Статьи — всё здесь, база не нужна
Писать, править, переводить статьи и готовить картинки — по навыку
`.agents/skills/bimcore-content-editor/SKILL.md` и его папке `references/`. Это единственный источник правил
статей (стиль, структура, шапка, MDX, картинки, FAQ, карточка товара, проверки). Штатные компоненты — по
`src/theme/MDXComponents.js`, самодельный HTML вместо них не писать. Статьи публикует только редактор
(кнопка «Опубликовать»); без явного разрешения владельца ничего не отправлять на сервер.

## Внутренние правила проекта — в базе владельца
Ветки, код сайта и редактора, процессы помощников — в базе знаний владельца (`it/web/learn/repo-rules.md`,
через MCP obsidian, после `CLAUDE.md` базы и `meta/assistants-global.md`). Нет доступа к базе — такую работу не
начинать и сказать об этом одной строкой; статьи по навыку выше делать можно.

## ⛔ DANGEROUS!!!!!!! Зависимости сайта

Никогда не удалять, не очищать и не заменять `node_modules` сайта целиком или частично без
предварительного сообщения владельцу с точной пометкой **`DANGEROUS!!!!!!!`** и его явного
согласия. Это относится также к `npm ci`, `npm prune`, ручной очистке, переносу и любому сценарию,
который сначала удаляет установленные пакеты. До согласия разрешены только проверки без записи.
Если зависимости основной папки или accepted-editor отсутствуют, а зависимости любой копии частичные
или повреждены, остановиться и сообщить владельцу с этой пометкой. Не использовать чужой или
родительский `node_modules`, временный `NODE_PATH` или другую рабочую папку как обход.

В новой временной копии зависимостей нет. До её создания ведущий определяет нужные проверки и, если
им нужны пакеты, включает в согласование копии точный путь и команду `npm.cmd ci` в нужном корне
копии и/или её `editor/` (команда скачивает пакеты). Уже данное точное согласие повторно не
спрашивается. После создания копии разрешённая установка выполняется до передачи исполнителю и только
если она нужна.

## Всегда
- Папка с материалами всегда на ветке `main`; в неё не коммитить, `pull`/`merge`/`reset`/`stash` не делать.
- Прямой `git push` статей запрещён; любая отправка на сервер, в том числе выпуск кода сайта, — только по прямому слову владельца.
- Это открытый репозиторий: код и внутренние документы редактора сюда не отправлять; ключи, токены и `.env*` не выводить и не коммитить.
