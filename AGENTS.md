# AGENTS.md — вход для Codex

## ⛔ DANGEROUS!!!!!!! Зависимости сайта

Никогда не удалять, не очищать и не заменять `node_modules` сайта целиком или частично без
предварительного сообщения владельцу с точной пометкой **`DANGEROUS!!!!!!!`** и его явного
согласия. Это относится также к `npm ci`, `npm prune`, ручной очистке, переносу и любому сценарию,
который сначала удаляет установленные пакеты. До согласия разрешены только проверки без записи.
Если зависимости отсутствуют или повреждены, остановиться, сообщить владельцу и не использовать
чужой `node_modules`, временный `NODE_PATH` или другую рабочую папку как обход.

Общие правила сайта и базы — в [CLAUDE.md](CLAUDE.md). Для редактора сначала прочитать
[состояние процесса](editor/process/README.md), затем `editor/CURRENT_TASK.md`.

Роли, выбор достаточной работы, замена при лимитах, проверка и приёмка — только
[Действующий процесс](editor/TASKS.md#действующий-процесс). Ведущий координирует и вовремя
останавливает работу; обычный путь не включает его повторный аудит кода. Читать относящиеся
к операции разделы, не весь справочник. Технический контролёр не ведёт Obsidian.

После сжатия контекста восстановить цель и следующий шаг из CURRENT_TASK, результат — из
совпадающего handoff и фактического Git. Устаревшая карточка не является командой повторить
завершённую операцию. Историю технической проверки в основной контекст не переносить.
По фразе «проверь Claude» применять [codex-gate](.agents/skills/codex-gate/SKILL.md).

Статьи, редактор и код сайта — три маршрута в разделе «Ветки и папки» [CLAUDE.md](CLAUDE.md).
Статья не проходит через менеджера и контролёра кода: её ведёт та сессия, куда написал владелец.
В начале сессии и перед итогом `npm run repo:check` показывает состояние, но не разрешает уборку.
Изменённый порядок документов проверяет один независимый собеседник; при недоступном Claude
используется разрешённый заменяющий агент, без повторного аудита функционального кода.
